评价置顶

更新于 2026-05-12 16:03:22 · 来源 global-help.ozon.com

评价置顶是一项旨在提高买家信任度和购买转化率的工具。置顶您认为对买家有用的评价 —— 它将以以下方式显示：

  • 商品卡片上的单独模块 —— 买家可以在不进入所有评价页面的情况下阅读该评价；

  • 在所有商品变体的评价列表中排在首位。

置顶评价

  1. 打开 商品 → 评价置顶 页面。

  2. 点击想要置顶评价的商品旁边的 选择一条评价

    对于单个商品，您只能选择一条评价。

  3. 选择您认为对买家最有帮助的评价。点击评价文本的行以查看完整内容，并点击 置顶 。

选择评价前，请确保它适用于合并到同一商品卡片的所有商品 —— 评价将被置顶至所有商品变体。

当您置顶一个评价后，我们将开始在商品卡片上突出显示它，并收取 服务费 。

  1. 请转到 商品 → 买家评价 部分。

  2. 在 评价 列中选择要置顶的评价。

  3. 在 评价置顶 板块中点击 置顶 。

在选择评价之前，请确保它适合所有合并至同一张卡片的商品——评价将为商品的所有变体置顶。

如何在Ozon Seller应用中置顶评价

替换评价

  1. 打开 商品 → 评价置顶 页面。

  2. 选择已经开通服务的商品 — 这包括所有状态为“评价已置顶”，“没有已置顶的评价”或“置顶错误”的商品。使用状态筛选器来更快地找到所需商品。

如果已开通服务的商品没有库存，它将不会显示在总列表中。要找到它，请使用状态筛选器或通过名称或货号进行搜索。对于这些商品，服务仍然是活跃的，评价也会被置顶。

  1. 转到商品的评价：对于状态为“评价已置顶”的商品，点击已选评价的行；对于其他商品，点击 选择一条评价 。

  2. 从列表中选择另一个评价：点击评价行，查看详情并点击 替换评价 。

我们将开始在选定商品及其所有变体上显示新的置顶评价。

  1. 请转到 商品 → 买家评价 部分。

  2. 选择已开通服务的商品。根据名称或货号使用搜索字段。

  3. 在 评价置顶 板块中点击 替换为此评价 。

我们将开始在所选商品和它所有的变体上显示新的置顶评价。

取消置顶评价

  1. 打开 商品 → 评价置顶 页面。

  2. 点击状态为“评价已置顶”的商品。

  3. 点击表格中的第一个评价或商品名称下的区块 —— 将打开置顶的评价。

  4. 点击 取消置顶评价 .

从此刻起，该评价将不再在列表中排在首位，也不会作为独立区块显示在商品卡片及其所有变体上。

从下一个周期开始，Ozon将不再收取此商品的置顶评价费用。

如果在已付费周期结束前您想为同一商品置顶另一条评价，Ozon不会收取额外费用，而从下个周期开始将按正常时间表继续收费。

  1. 请转到 商品 → 买家评价 部分。

  2. 找到并打开您想置顶的评价。置顶的评价将在 状态 列中标记为 。

  3. 在 评价置顶 板块单击 解除绑定 。

从这一刻起，评价将不会在列表中第一个显示，也不会在商品及其所有变体的卡片上以单独板块的形式显示。

从下一期起，Ozon将不再为该商品的评价置顶而收取费用。

如果您想在付费期末之前为该商品再置顶一条评价，Ozon将不会收取额外费用。而从下一期开始，Ozon将继续按照常规时间表来收取该费用。

"评价置顶"服务

“评价置顶”服务状态

服务状态 描述
"评价已置顶" 评价已在商品卡上置顶 —— 服务处于活跃状态，Ozon 收取费用。 无论商品评级如何，都可以置顶任何评分的评价。
"没有已置顶的评价" 您已取消置顶的评价 —— 在已付费周期结束后，Ozon 将停止收费，此商品的服务状态将变为“评价已取消置顶”。在此之前，您可以置顶另一条评价，不需支付额外费用。
"评价已取消置顶" 您已取消置顶的评价 — 服务不再有效，Ozon 停止收费。
"置顶错误" 买家可以删除或编辑评价。如果置顶的评价被修改，商品状态将变为“置顶错误” — 在此期间不会有置顶评价。要使置顶评价重新显示在商品卡上：
- 如果买家编辑了评价 — 检查修改后的版本，并决定是否保留此评价为置顶状态或选择另一条评价；
- 如果买家删除了评价 — 选择另一条评价进行置顶。

如果您想停用某商品的服务，无需采取任何操作：如果您不保留修改后的评价也不选择另一条评价，服务将在已付费周期结束后停止。

如果您将商品归档，服务状态也会变为“置顶错误”。某商品的服务将在已付费周期结束后停止。

下载分析报告

  1. 请转到 商品 → 评价置顶 部分。

  2. 点击 附加信息 → 以Excel格式下载分析报告 。

在XLS报告中将显示使用服务的整个期间的数据：

  • 服务提供日期，

  • SKU，

  • 卢布支出。

支付评价置顶服务费

Ozon 每天收取一次费用 — 对每条置顶的评价收费。如果有多条置顶评价，将扣除总费用。同时，您可以更换评价，不会产生额外费用。

如果一条评价同时为多个合并到同一商品卡的商品变体置顶，这不会增加费用 — Ozon 会对单条评价收费。

关于服务费用详细信息

您可以在以下位置查看服务费用：

  • 财务 → 余额 → 服务 页面— 评价置顶 一栏。

  • 财务 → 商店经济状况 → 附加服务 页面, 应计类型 — 评价置顶 。 点击应计金额查看详细信息。
