订单包装要求

更新于 2026-09-30 08:40:57 · 来源 global-help.ozon.com

一般要求

  • 确保包装内物品不能被轻易取出，包装或容器完好无损、干燥、清洁。

  • 考虑商品的特性，以确保在配送和运输过程中不会破损或损坏其他货件。

  • 单独包装货件的突出部分。

  • 尽量紧密地堆放商品，以确保内容物在包装内部不会移动 — 可以用纸张或报纸填充空白空间。

  • 确保货物箱上没有旧标签，所有指示性标志都是最新的。

  • 将危险货物单独包装在盒子里。

  • 在有特殊储存和运输条件的货物上加贴相应的标签和指示性标志，并附上相关处理说明。

  • 准备标签。 在 物流→来自我的仓库的订单 模块中点击 下载→标签 。如需下载特定订单的标签，请勾选相应订单后点击 标签 。

  • 从Ozon个人中心打印标签并将其贴在包装上。请确认标签：

    • 使用热敏打印机或热转印打印机打印；

    • 已完整打印：文字和二维码边缘未被裁切；

    • 不含其他文字、标志或店铺标识；

    • 以完整图像形式打印：如果标识破损或由多个碎片拼接而成，承运商将无法接收该货件；

    • 表面为哑光或半光；

    • 粘贴在包装最大的一面；

    • 整面粘贴在包装上，无空隙、无未粘合区域。

  • 请检查二维码是否：

    • 打印清晰；

    • 未被胶带覆盖；

    • 不影响商品外观，包括商品原厂包装。

您可以将标签打印在任意规格的纸张上。

标签示例

  • 对于易碎商品的货件，必须标注“请勿抛掷。易碎物品”。如果商品在配送过程中受损，买家可以退货并留下差评。以下商品属于易碎商品：

    • 玻璃和陶瓷制品、镜子、吊灯；

    • 小雕像、花瓶；

    • 器皿 — 例如玻璃和陶瓷制的杯子、酒杯、玻璃盖子等；

    • 玻璃瓶咖啡；

    • 陶瓷罐茶叶；

    • 所有无单独包装的玻璃罐液体商品；

    • 无单独包装的玻璃相框、钟表和带玻璃的画；

    • 无单独包装的陶瓷刀；

    • 电子产品：手机、智能手机、平板电脑、通讯设备、记录仪、导航仪、硬盘、电子书、数码相框等。

CEL 轮胎运输与包装规范

轮胎必须沿货物外缘进行缠绕包装,必须保留中心孔洞(即中间的空心部分要保持可见)。禁止将轮胎完全缠绕封死(即不允许覆盖中心孔).

潜在危险商品的包装要求

在交货潜在危险商品时，请特别注意包装的完整性和密封性：

  • 外部包装必须坚固，防止接触内部物品，并避免机械损坏；

  • 使用缓冲材料，对内部包装部件提供额外保护和缓冲；

  • 包装上不得有泄漏或损坏的痕迹；

  • 盛放液体的容器必须垂直放置，瓶盖或塞子必须紧密封闭或密封，包装外部必须标有“此面朝上”的方向标志。

  • 商品上的危险图标、警示词语或提示标签，必须显示在外部包装上，表明危险性质或易碎内容。

  • 带有蓄电池的设备和装置必须包装妥善，以保护开关，防止意外启动；

  • 包装内的蓄电池必须做好绝缘，防止短路。必须避免与任何液体、金属物品或其他导电材料接触。

额外包装

请确保将订单包装得结实且紧凑。过多的包装材料可能会影响 商品的体积重量 。

某些商品需要额外的包装以防止损坏。

商品

如何包装

易碎商品，例如玻璃制品、镜子、显示器、电视机

用发泡聚乙烯或气泡膜包裹，边缘用胶带封好，并额外装入纸箱中

Apple 设备、智能手机、智能手表和健身手环

用气泡膜包裹并装入保密袋或快递袋

液体商品，例如化妆品、香水、散装商品等

放入袋中，数量不要超过5个。将袋子密封并放入一个纸板箱里进一步包装

宠物饲料和宠物砂

放入袋中，将袋子密封或用白色或黑色不透明的哑光拉伸膜包装

易弯曲的大件商品，例如日历、海报、地图等

放入圆柱形纸盒中

可能受潮损坏的商品，例如书籍等

用白色或黑色不透明的哑光拉伸膜包装

由多个盒子组成的商品

将所有盒子放入一个纸箱中

如果商品在运输过程中损坏，买家可能会将其退还并留下负面反馈。为了避免这种情况，仔细包装每个商品：

  1. 用几层发泡聚乙烯、聚乙烯或气泡膜将商品完全包装起来。用胶带密封商品的边缘。

  2. 将突出部分用塑料、纸板或泡沫角片保护起来。

  3. 在包装中添加泡沫塑料或纸板加固条。

  4. 在纸箱的侧边上添加纸板角片支撑。

  5. 用五层纸板制成的箱子包装商品。

  6. 牢固地将商品固定在纸板箱内。在商品和纸板箱之间放置填充物：纸、泡沫塑料或瓦楞纸板。额外包装脆弱部分，例如屏幕等。
    轻轻摇晃纸板箱 - 商品不应在内部移动，各部分不应互相撞击和与包装边缘接触。

  7. 如果商品易碎：

    • 贴上“易碎货物”标签。

    • 添加警告文字：“小心，易碎商品！”，“易碎货物！”，“请勿踩踏！”。

    • 贴上红色或黄色的胶带。

    • 标明商品的顶部位置。
