订单取消

更新于 2026-09-15 13:42:13 · 来源 global-help.ozon.com

买家取消订单

买家主动取消不影响 错误指数 并不导致 罚款 .

买家可以取消订单:

  • 商品发运前——若订单尚未转交承运商，订单将自动取消，商品退回库存。请勿将此类订单转交承运商。

  • 送达Ozon取货点后——若买家在14天内未取货。

  • 收货时拒收——若买家在快递送达前或在Ozon取货点当场拒绝订单。

要查看取消原因：

  • 对于所有订单，请前往 物流 → 来自我的仓库的订单 → 已取消 模块。

  • 对于发货后被取消的订单，请前往 退货 → 退货和取消 → 全部 模块。

未认购订单

未认购是指买家在取货点拆开包装并检查商品后，拒绝了全部或部分订单的情况。

关于未认购商品的信息显示在 退货 → 退货和取消 部分中。“原因”栏中将显示“买家拒绝取货”。

未认购商品类型：

类型

描述

后果

整单

买家拒绝整笔订单。

订单全额取消，无需支付配送费用。

部分

买家拒绝部分商品。

您可获得已交付商品的货款，但需支付整单的配送费用。

卖家取消订单

所有由您主动或因您过错导致的取消都会影响 质量指标 。其中部分取消会导致 realFBS错误指数 上升及 罚款 。

卖家主动取消

如果您按rFBS或FBP模式销售

您只能在“等待发运”、“等待备货”、“已准备发运”状态下取消订单。如果您通过中国邮政（China Post）以外的合作配送服务配送，也可以在“运输中”状态下取消订单。

 如果您按OGL模式销售

您只能在“等待备货”和“已准备发运”状态下取消订单。

您可以选择以下取消原因之一：

  • 仓库缺货 ——商品数量将自动归零。 此后，您可以补货并填写新数量，或将商品卡片归档。

  • 其他（卖家过失） ——如果列表中没有合适的原因，请选择此项并描述情况。

若配送过程中出现问题，合作配送服务将取消订单。

如何取消订单：

  1. 在 物流 → 来自我的仓库的订单 部分选择相应货件。

  2. 点击 → 取消货件 。

  3. 选择原因并确认取消。

卖家过失取消

因逾期发货而取消

如果您在计划发运日期后7个自然日内未将货件转交承运商，订单将被自动取消。

为避免取消：

  • 请检查您在个人中心中设置的仓库工作时间。

  • 请确认订单准备时间切合实际并符合您的能力。

  • 如果商品缺货，请在补货前隐藏其商品卡片。这将避免您无法按时完成的订单进入。

Ozon取消订单

如果订单违反 要约 规则，Ozon可能会取消该订单。取消原因显示在 物流 → 来自我的仓库的订单 → 已取消 部分的“取消原因”栏中。

Ozon取消订单的主要原因：

 如果您按rFBS或FBP模式销售

  • 买家未在48小时内提供护照信息。

  • 您未在计划日期后7天内将订单转交承运商。

  • 延迟超过20天时买家要求取消订单。

  • 追踪号码无法追踪或未提供。

  • 配送服务报告存在禁运商品或不符合要求的情况。

  • 订单在配送服务中丢失或损坏——不影响质量指标。若无法找到订单，Ozon将向您支付赔偿。可在 财务 → 文件 → 赔偿及其它应计项目 部分中查看赔偿的应计情况。

如果您按OGL模式销售

  • 买家未在48小时内提供护照信息。

  • 您未在计划日期后7天内将订单转交承运商。

  • 延迟超过20天时买家要求取消订单。

  • 配送服务报告存在禁运商品或不符合要求的情况。

  • 订单未获出口或进口海关放行。

  • 订单在配送服务中丢失或损坏——不影响质量指标。若无法找到订单，Ozon将向您支付赔偿。可在 财务 → 文件 → 赔偿及其它应计项目 部分中查看赔偿的应计情况。

请务必上传条形码并将其贴在商品上，否则如果商品在运输中丢失，我们将无法支付赔偿。
