其他服务开支

更新于 2026-09-23 15:13:59 · 来源 global-help.ozon.com

品牌推广佣金

在搜索结果、目录和品牌精选中推广品牌。

服务费率：每件商品由卖家设定的价格的1%。服务记录日期为下单日期，计费日期为订单送达日期。已送达商品需收取佣金，无论买家签收商品还是退货，1%的佣金均不退还。

“品牌推广”技术服务费会在完工单中列明。

了解更多关于“品牌推广”服务的信息

面向推广品牌商品的“Morkovsk”促销活动

该服务自2026年6月29日起开放。

在“Morkovsk”促销活动中，Ozon买家可以：

  • 因购买已参加促销活动的商品获得胡萝卜；

  • 参加抽奖，将胡萝卜兑换成有价值的奖品。

服务费率：卖家为每件商品设定的价格的0.5%。服务记录日期为下单日期，计费日期为订单送达日期。已送达商品需收取佣金，无论买家签收商品还是退货，0.5%的佣金均不退还。

该服务不能与“品牌推广”服务分开提供。“品牌推广”技术服务费会在完工单中列明。

试用期

如果此前未推广的品牌变为推广品牌，您该品牌下的商品将自动开始推广，并接入“Morkovsk”促销活动。我们会在个人中心向您发送相关通知。

免费试用期为3天。在此期间，商品将进行推广并参与“Morkovsk”促销活动，无需支付额外费用。试用期结束后，我们将开始收取品牌推广费用和参与“Morkovsk”促销活动的费用。试用期结束前，您可以决定是否继续让商品参与品牌推广和“Morkovsk”促销活动，或关闭该服务。

您可以暂停商品参与“Morkovsk”促销活动，同时保留品牌商品推广。

除其他服务费用外，卖家的费用结构还包括：

  • 按类目收取的商品销售代理佣金

  • 配送费用计算

图片编辑器

在Ozon的图片编辑器中，卖家可以编辑图片：

  • 智能补全边缘，

  • 生成背景，

  • 删除背景，

  • 提高图片质量。

背景生成功能每天最多可使用50次，其余效果每天最多可使用80次。编辑后的照片可发布到商品卡片。

Ozon的照片编辑费用已包含在销售佣金中。

OzonGenerator  

卖家使用OzonGenerator服务在商品卡片中生成简介。每月使用OzonGenerator生成简介的次数不超过200次。

Ozon就使用OzonGenerator生成内容收取的代理佣金已包含在销售代理佣金中。

银行收单手续费

收单业务的费用全部用于合作银行服务费用的支付。Ozon的代理佣金包括在 定购人商品国际运输组织的代理佣金 中。

收单是指卖家接受顾客的非现金支付。服务完全由合作银行提供。

结算文件：我们将在下个月的第5个工作日之前和8号之前，将 重新提供服务报告（委托执行） 上传至 财务→文件→代理报告 部分。报告中将包含报告期内由每个合作银行提供的服务信息。

费率由处理买家付款的银行设置。

Premium Lite、Premium、Premium Plus和Premium Pro订阅费用

Ozon Technologies LLC服务的付款程序：

  • 您指示奥宗从您个人账户中的奥宗余额中扣留资金，并向Ozon Technologies LLC进行资金转账，以履行您根据 Ozon科技服务合同所承担的付款义务 。

  • 在扣款发生后，在 财务→文件 部分， 奥宗 出具《扣款通知》，并每月出具《扣款报告》。

  • 支付服务款项的义务在相应金额范围内，于从奥宗余额中扣款且奥宗向您的个人账户发送《扣款通知》之时视为已履行，无论奥宗随后向Ozon Technologies LLC转账合计资金款项的日期如何。您个人账户余额中的资金数额将相应减少。余额减少后：

  • 您的指示在相应部分视为已履行。

  • 相应金额由奥宗记为应转账给Ozon Technologies LLC的金额。该金额不再计为可用余额，且不能用于清偿对奥宗的其他义务。

“收集首批评价”服务

可以从2026年7月15日起开通“收集首批评价”工具，但我们会在启动后7天才开始把您的商品推荐给顶级作者撰写评测，即从7月22日起。

该工具帮助卖家从顶级作者那里获得商品的详细评价。我们仅对非匿名的5星评价收费，评价需包含视频和不少于5个字符的文字。评价会发布在“评价动态流”中，并固定在商品卡片上。只有在没有“评价管理”或Premium Pro有效订阅的情况下，评价才会被固定；固定有效期为30天。仅在收到评价后收取服务费。

费用按卖家合同中的币种收取。应付金额以卢布计算，并按照商品下单日期的俄罗斯央行汇率换算，公式如下：

单条评价费用 = S + P + B

其中：

  • S——固定出价，金额为300卢布；

  • P——商品销售价格，已包含所有折扣和促销活动；

  • B——买家使用的Ozon积分。

P + B的金额不得超过10,000卢布。

示例

购买时，商品销售价格在包含所有折扣和促销活动后为1000卢布。买家使用了已累积的Ozon积分——200卢布，实际支付800卢布。我们将对该条评价扣除：300 + 800 + 200 = 1300卢布。买家将获得1000卢布等值的积分。

折扣和试用期：2026年7月15日至2026年9月15日，单条评价的固定出价300卢布享受折扣。使用服务时，我们仅扣除可变部分——向顶级作者发放的积分数量，金额等于商品购买时已包含所有折扣和促销活动的卢布销售价格，但不超过10,000积分。

如果评价在发布后被修改、编辑或删除，费用不予退还。
