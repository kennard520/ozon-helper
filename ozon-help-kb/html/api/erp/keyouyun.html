ERP介绍

客优云隶属于湖南智六网络科技有限公司，2018年开始深耕跨境电商和企业服务领域，是最早一批提供跨境SaaS服务的企业。公司聚焦于跨境ERP系统以及软件工具的研发，致力于为企业和用户提供最优质的跨境服务。 截止2023年6月，客优云累积注册用户超30万，日可处理订单量超5000万，合作优质物流商50多家。是Ozon、Shopee、TikTok Shop、Lazada等多家平台的官方认证及最佳ERP合作伙伴，提供采集、刊登、定价、订单、仓储、采购、物流、代打包、财务等一站式跨境服务。
