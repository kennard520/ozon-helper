促销积分

更新于 2026-06-02 09:25:21.563187 · 来源 global-help.ozon.com

Ozon可以为参与活动和问卷调查的人返积分 调查：1奖金=1卢布。积分可以在活动中使用，但不能换成钱。 Ozon向您发送有关活动的信息并通过电子邮件进行问卷调查，并且在个人主页和Ozon主页同步显示 Ozon Seller 。

您可将积分花在推广工具上:

  • “按订单付费” ,

  • “按点击付费” 。

积分类型:

  • 通用奖励金 — 可用于媒体广告和按点击付费的推广。

  • “按订单付费”积分 — 可用于推广所有按订单支付的商品。

  • “按订单付费”积分（指定商品）— 可用于推广指定商品的按订单支付。

  • “按点击或订单付费”奖励金（针对特定商品） — 可用于推广指定商品，通过“按订单付费”或“按点击付费”的方式进行。

积分的计算和扣减

在参与活动或完成问卷调查后，积分将被自动计入您的账户或在使用 优惠码 后。积分可以在他们的到期日前被使用。

如果积分被计入到指定商品的推广，您可以查看这些商品的 SKU 列表。为此，请点击靠近积分类型的商品数量图标。

推广时首先使用积分，然后才使用卢布。同时首先将使用即将过期的积分。

活跃的广告活动每天都会使用积分。在计算周期结束时，您只需支付超出积分的金额。

您可以使用积分支付推广费用的99%。剩余的1%将在报告期结束时以卢布扣除，并立即以通用积分返还。积分可以在当年年底前使用，除非在个人中心中另有规定。您可以使用积分支付推广费用的99%。在结算周期结束时，我们会以卢布的形式扣除 1%，并以一般积分形式返还。这些积分会在计入当年的年底失效。已发放的积分可使用至本年度年底，除非在个人中心中另有指定期限。 在使用其他推广工具时，系统会优先扣除用于特定商品的积分，其次扣除最先到期的积分。

积分扣除示例：

  • 您的账户有700个按订单付费的积分。您开启了按订单付费，并花费了700卢布的积分 — 这就是100%。我们将扣除693个积分，并在月底再扣除7卢布（即广告活动费用的1%），同时将7个通用积分返还到您的账户。

  • 您的账户有：

    • 500个一般积分，有效期至8月2日；

    • 500个按点击或订单付款的积分，仅限于指定商品（SKU 12345、12346），有效期至12月1日。

您已在推广指定商品 SKU 12345、12346 的按点击付费广告中花费了900卢布。首先会扣除500个“按点击和订单付款”类型的积分（用于指定商品），然后再扣除391个一般积分。月底时，我们会从您的账户再扣除9卢布（即活动费用的1%），并返还9个一般积分到您的账户。

要花费积分，请自行启用推广广告活动。

检查积分信息

  1. 请进入 推广 → 按点击付费或按订单付费 → 更多 → 费用详细信息 。

  2. 在 积分 板块点击 交易历史记录 。

    与您的积分账户相关的交易如下：

    • 扣款 — 自动用于支付正在进行的推广活动的积分。

    • 累积 — 通过促销码获得的积分。

    • 调整 — 平台方对积分的增加或扣除。如有积分计入错误，系统会进行扣除。

    • 过期 — 未及时使用的积分。

  1. 请进入 推广 → 按点击付费或按订单付费 → 更多 → 费用详细信息 。

  2. 在 积分 板块点击 交易历史记录 。

  3. 点击 下载报告 。

    报告中将展示：

    • 扣款日期；

    • 广告活动ID；

    • 广告活动名称；

    • 推广类型 — 积分用于哪个推广工具；

    • 积分 — 扣除的积分数量；

    • 商品积分 — 针对具体商品扣除的积分数量；

    • ID SKU — 如果针对具体商品扣除积分，将显示商品的唯一标识。

如果积分还没有入账

如果您在参与活动或完成调查后没有收到积分或优惠码， 联系客服 。 为此，请在个人中心的屏幕底部点击 → 创建申请: «广告费用明细» 。

优惠码

对于参与活动或参加问卷调查，您可以获得含有积分并可以花在促销上的优惠码。一些优惠码有期限和激活条件，例如，您只能把积分花在您的第一个广告攻势上。 激活期过后，您将无法使用优惠码。

要激活优惠码，在 费用细目 页，在 激活优惠码 栏中，输入优惠码并点击 激活 。
