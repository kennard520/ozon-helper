品牌推广

更新于 2026-09-07 13:26:39 · 来源 global-help.ozon.com

如果您有欠款，您将无法使用促销工具。当余额变得正数时，我们将恢复对其的访问。

如何查看您的余额

您可以推广您所销售商品的品牌。这样您的商品对买家而言将更加醒目。

优势

在Ozon推广的品牌特点：

  • 在筛选器中显示品牌标志，让买家设置搜索筛选条件时更容易注意到该品牌；

  • 在筛选器的品牌列表中排在靠前位置；

  • 当买家开始在搜索栏输入品牌名称时获得突出显示：我们会在推荐选项列表中显示带标志的品牌名称；

  • 如果销量优于该类目其他品牌，就会获得类目部分“流行品牌”货架位。

  已开通推广的品牌商品：

  • 在目录和搜索结果中通过品牌名称突出显示，让商品在未推广的竞争对手商品中更加醒目；

  • 在商品卡片中通过品牌名称和标志突出显示；

  • 在搜索结果和类目中显示时，商品图片上会带有标志；

  • 买家可以从商品卡片跳转到包含该品牌所有商品的页面。

该服务为付费服务。推广会按卖家设定的 最高价格 的固定百分比扣费。 了解更多推广费用信息

管理品牌商品推广

接入品牌商品推广

我们可以检查您的品牌文件，这些文件将确认您可以销售这些商品。如果没有这些文件，我们将不得不对买家隐藏商品。在这种情况下，品牌推广费用将无法退还。

当您首次开始销售推广品牌的商品时，推广将自动开通，并在3天内不收取额外费用。在个人中心，这些品牌会标有图标 。

我们会在您创建或编辑商品卡片时标注您的商品品牌是否已开通推广：

  • 手动创建新商品时，我们会显示其中是否有在Ozon推广的品牌；

  • 编辑单个商品或整组变体并更改品牌时，如果您在商品卡片中填写的是正在推广的品牌，我们会进行提示；

  • 通过模板或API批量上传新商品时，如果您首次上传这些品牌下的商品，我们会在个人中心向您发送通知。我们会显示您的新商品中哪些品牌参与推广，您可以决定是保留商品推广还是关闭服务。

商品保存并通过审核后，我们会自动在搜索结果和商品卡片中通过品牌名称突出展示该商品。可在 商品 → 品牌 → 品牌推广 部分管理推广。

Ozon可能会开始推广此前未推广的品牌。

如果此前未推广的品牌变为推广品牌，您该品牌下的商品将自动开始推广。我们会在个人中心向您发送相关通知。免费试用期为3天，商品将在不收取额外费用的情况下进行推广。

了解更多关闭推广的信息

试用期结束后，我们将开始收取推广费用。

了解更多推广费用信息

关闭品牌商品推广

只有拥有“主管”或“管理员”角色的用户可以管理品牌推广。

如需关闭商品推广，请打开 商品 → 品牌 → 品牌推广 部分，并将所需品牌旁边的 推广商品 开关切换为非激活状态。商品将停止参与品牌推广，我们也将停止扣费。

如果您想再次推广商品，请开启开关，但只能在关闭满24小时后操作。

  • 开关处于激活状态  ——推广已开启

  • 开关处于非激活状态   ——推广已关闭

您也可以在个人中心的 商品 → 品牌 → 品牌推广 部分设置“在照片上显示商标”。如果品牌商品推广已关闭，则无法在商品图块上展示品牌标志。

管理推广品牌商品接入“Morkovsk”促销活动

“Morkovsk”是面向买家的游戏机制。目标是收集并使用尽可能多的“胡萝卜”，这是参与丰厚奖品抽奖的促销活动专用货币。如果您的商品已接入促销活动，买家就可以因下单获得“胡萝卜”。

了解更多品牌推广中的“Morkovsk”促销活动信息

服务自2026年6月29日起开放。只有拥有“主管”或“管理员”角色的用户可以管理推广品牌商品接入“Morkovsk”促销活动。

推广品牌商品将随着品牌推广开始自动接入“Morkovsk”促销活动：

  • 当您首次开始销售推广品牌的商品时，如果您通过模板或API批量上传了新商品，我们会在个人中心向您发送通知。用图标标注，表示您在个人中心创建或编辑商品卡片时，可查看您的商品品牌是否已接入推广；

  • 当此前未推广的品牌变为推广品牌时，我们会在个人中心向您发送通知。

如果您已经在销售推广品牌的商品，Ozon可以自行将这些商品接入“Morkovsk”促销活动。在这种情况下，我们会在个人中心向您发送通知。

自动接入时，您将获得3天试用期，商品将在不收取额外费用的情况下参与促销活动。我们会将推广品牌的所有商品接入促销活动。

如需自行将推广品牌商品接入“Morkovsk”促销活动，请进入 商品 → 品牌 → 品牌推广 部分，并在 “Morkovsk”促销活动 列中将开关切换为激活状态 。这种情况下不提供试用期。

只要品牌商品仍在参与“Morkovsk”促销活动，就无法关闭品牌推广本身。如果您想关闭品牌商品推广，请先将商品从“Morkovsk”促销活动中移除。

推广品牌商品参与“Morkovsk”促销活动为付费服务。

了解更多费用信息

如果商品已通过 “按订单付费”工具 加入促销活动，则不会重复扣费，我们会按照“按订单付费”工具中参与促销活动的费用收取佣金。

了解更多“按订单付费”中的“Morkovsk”促销活动信息

将推广品牌商品从“Morkovsk”促销活动中移除

如需将推广品牌商品从“Morkovsk”促销活动中移除，请进入 商品 → 品牌 → 品牌推广 部分，并在 “Morkovsk”促销活动 列中将开关切换为非激活状态。Ozon会将商品从促销活动中移除，并停止收取佣金。关闭推广最早只能在开启满24小时后进行。

如果您想再次将商品接入促销活动，请将开关切换为激活状态。该操作最早只能在关闭满24小时后进行。
