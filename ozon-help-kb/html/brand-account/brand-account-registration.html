品牌个人中心注册

更新于 2026-08-10 09:18:17 · 来源 global-help.ozon.com

在满足以下条件时，您可以注册品牌个人中心：

  • 您已在 Ozon 平台销售商品。

  • 您是权利人、独占被许可人，或权利人/独占被许可人的授权代表。
    了解更多关于品牌代表要求的信息

  • 品牌已在Rospatent注册为商标，或通过马德里体系注册，并在俄罗斯联邦境内受到保护。

  • 品牌属于《商品和服务国际分类》（尼斯分类）第1至第34类中至少一个类别的商品。如需了解品牌属于哪个类别，请使用免费服务 Linkmark.ru 。

  • 您的商标为文字，或由文字与图形组合构成。

请在 设置 → 品牌代表 模块上传品牌相关文件。完成后，您即可切换到品牌个人中心，并监管其他卖家的产品质量。

上传代表文件

请在个人中心上传可证明您拥有或保护该商标权利的文件。仅“主管”和“管理员”角色的用户可以上传。质量部门专员将审核文件，通过后您即可使用品牌个人中心的全部功能。

上传文件步骤如下：

  1. 在 设置 → 品牌代表 模块中点击 成为官方代表 。

  2. 填写品牌信息：

    • 品牌名称：若列表中没有所需品牌，请点击 添加新品牌 并 提交申请 。

    • 商标注册体系：选择 俄罗斯联邦 或 马德里体系 。

    • 您的身份：选择 权利享有者 、 独家被授权商 或 品牌代表 。

    • 商标、许可或品牌权利的签发日期与有效截止日期。

    • 商标注册证编号，不含其他符号、零、空格和标点符号。 您可以查看编号：

      • 在纸质商标证书中；

      • 在 俄罗斯联邦知识产权局开放注册簿 中；

      • 在 Madrid Monitor 中；

      • 在任何在线商标搜索工具中，例如免费服务 Linkmark.ru 。

  3. 上传文件。
    关于文件及其要求的更多信息

  4. 点击 发送 。

审核时间取决于申请总数、文件包是否正确，以及所提供扫描件和照片的质量。总审核时间为14天。可能的状态：

  • “等待验证” ：申请在队列中等待审核；

  • “检查”：正在核查品牌信息及所提交文件；

  • “已通过检查”：文件无误，您可以成为品牌代表；

  • “已被拒绝”：需修正申请或文件中的错误。

为什么申请可能被拒绝

如果您成为经常被仿冒品牌的代表，我们会在文件审核通过后，免费为商品添加“品牌已认证”徽章。对于其他品牌，可以付费开通该徽章。

文件要求：

  • 照片或扫描件需清晰——文字、印章和签名必须清楚易读；

  • 格式：JPEG、JPG、PNG、PDF；

  • 单个文件大小：不超过10MB；

  • 文件不得加密——带密码的文件将不予受理。

注册第二个品牌中心

注册第二个品牌中心时，请填写另一个电子邮箱。“主管”角色的邮箱必须对每个中心都是唯一的。

如果您同时通过品牌代表账号和其他账号在Ozon销售，店铺商品范围的重合度不得超过30%。否则，根据合同规则，我们会停用除一个账号外的所有账号。

更换品牌代表

一个品牌在平台上只能有一个代表，我们会根据文件的法律效力选择代表。如果您想更换代表，请联系 客服 ： 个人中心 → 品牌中心 → 注册与激活品牌中心 。请在请求中附上 文件 。 我们会审核申请。如果您的文件：

  • 法律效力相同或更低，代表将保持不变。

  • 法律效力更高，品牌中心将转移给您。例如，如果您是商标所有人，而当前代表是拥有代表和保护品牌权利的分销商。

代表申请被拒的原因

在以下情况下，您的申请可能会被拒绝：
