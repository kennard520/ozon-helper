商标授权证明文件

更新于 2026-09-24 08:15:16 · 来源 global-help.ozon.com

根据俄罗斯联邦的法律法规和商标持有者的要求，Ozon 为上传和销售某些品牌的商品制定了特别规则。

在Ozon平台注册品牌并不意味着自动获得商标所有权。若想取得该权利，需在认证机构（如俄罗斯联邦知识产权局）注册品牌。

如何提交申请

在上传这些品牌的销售授权证明文件之前，您不能：

  • 如果您在 Ozon 上曾经出售此类品牌的商品，您就无法继续销售。这些商品将被隐藏。

  • 如果您尚未在 Ozon 上出售此类品牌的商品，您就无法创建或上传新的商品。

为了在 Ozon 上销售在俄罗斯或国际知识产权体系中注册其商标或商业牌号的品牌商品，则需提供品牌使用授权文件。

如果您已经开始上传商品，可以在 商品 → 品牌文件 模块中查看哪些品牌在销售时需要获得权利人许可。

Ozon仅接受商品所属的第1至34类尼斯分类。如果您的文件中包含第35类（服务类），该文件将被拒绝。

哪些品牌需要确认正品保证

如果您销售的商品属于流行且经常被仿冒的品牌，请确认其正品保证：

  • 上传 品牌文件；

  • 缴纳 品牌保证金。

    需要确认正品保证的品牌.xlsx (13 KB)

    品牌列表可能会发生变化。如果未确认正品保证，我们将隐藏该品牌的商品。

商标授权证明文件

证明您有权上架商品的文件包括：

  • 商品商标注册证书，或来自俄罗斯专利和商标局或WIPO Madrid公开来源的摘录（需在提交申请时有效）；

  • 许可协议；

  • 分销协议；

  • 商标所有者关于在俄罗斯境内销售商品的许可函；

  • 证明您从授权经销商处购买商品的销售收据；

  • 其它文档。

需要提供的文件取决于 您的销售权授予方案 。

文档要求

授权销售证明文件可以是协议或以自由形式写成的许可证，并且必须包含：

  • 签发日期。

  • 文件有效期。不接受无限期文件。

  • 商标所有者的签字或印章。

  • 注明在俄罗斯联邦境内的销售权.

如果您认为有人在 Ozon 上非法销售品牌商品，请与客服人员联系。为此，请单击 链接 或在个人中心中窗口底部单击消息图标，然后选择 其他 → 创建申请 。然后选择 质量控制 主题和 其他卖方违反了网站规则 二级主题。

    • 您与授权代表的协议。例如，许可协议、分销协议、销售和购买协议。

  • 以下文件之一：
    • 您与供应商的合同。
    • 证明您与供应商之间商业合作事实的文件（例如，通知、信函）。
  • 以下文件之一：
    • 供应商与授权代表的合同。例如，许可协议、分销协议、销售和购买协议。

如果商标注册信息中权利人或被许可人的数据在俄罗斯专利和商标局的注册表中隐藏，请附上一份来自俄罗斯专利和商标局的证明，其中包含权利人的信息、通信地址以及使用商标的协议双方。

在俄罗斯专利和商标局网站上了解更多关于如何获取证明的信息

如果供应链内所包含的参与者多于上述数量，则必须按上述示例为每个参与者提供完整的文件包。

在工业贸易部目录中商品的销售

俄罗斯工业贸易部已将平行进口合法化，并在 其网站上 发布了允许平行进口的商品目录。如果您的商品在此目录中，您需要确认以下内容：

  • 您的商品必须是正品，而不是复制品。为此，您必须提供与版权所有者 / 分销商 / 供应商的合同，该合同的主要文件：发票等。
    Ozon 还可以要求提供确认版权所有者在出口国境内的品牌权利的文件。

  • 您的商品必须在合法建立的商品目录中。在这种情况下，您需要证明您进口的商品海关税则编码（HS 码）与 目录 中商品的 FEACN（对外经济活动的商品命名，“ТН ВЭД”）编码相同。
    证明文件包括报关单、包含您在我们平台上出售商品的海关税则编码（HS 码）的其他任何文件。

请注意，对于 目录 中的商品，您无需要提供确认在俄罗斯联邦境内该品牌销售权利的文件。

您可以自行在公开来源中找到当前有效的平行进口允许商品清单。

如何上传证明文件

  1. 在个人中心的 商品 → 品牌文件 一栏目中，单击 添加文件 。

  2. 输入证明文件的详细信息及有效期。不接受无限期文件。

  3. 上传电子文件，大小不得超过10 MB。

  4. 点击 添加文件 。

品牌文件将送检。 这通常需要5-10个工作日。 请在 商品 → 品牌文件 部分监控状态。 如果文件有问题，状态将更改为“被拒绝”，并附有原因。

通过审核之后，您将可以在 Ozon 上出售该品牌的商品：一天之内，在该品牌的商品信息页上将出现有关品牌销售权的信息。

“品牌已认证” 徽章

如果您销售的是热门品牌商品，且该品牌在市场上经常出现仿冒品：

  • 上传权利人文件。我们将在审核通过后免费展示徽章。

  • 如果您不是权利人，请缴纳 保证金 。
