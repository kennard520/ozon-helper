视频上传

更新于 2026-07-17 08:19:21 · 来源 global-help.ozon.com

所有视频都需要通过审核。请上传符合商品的视频。

如果商品有几种型号选项，您可以 将它们合并至一张卡片 。

通过商品卡片

  1. 填写商品属性并进入 媒体 。在 视频 板块点击 添加 。

  2. 使用下列方法之一上传不多于5个视频：

    • 将文件拖入上传区域。

    • 点击 并从电脑中添加视频。

    • 输入VK Video, Yandex Disk或Rutube链接。如果您想添加多个链接，请按顺序将其附加。

    VK Video, Rutube链接——在浏览器地址栏中复制视频链接。
    Yandex Disk链接——文件或含有多个视频的文件夹的链接。

    链接应该是怎样的，如何复制它

    添加的视频可以被删除并更改位置。

    如果Yandex Disk在您的地区不可用，请使用其它可选的上传方法。

  3. 点击 保存 。无需等待上传结束——上传将在商品创建之后开始。

  4. 填写其它的商品属性并点击 添加 。

    5. 您可以使用 模板 来将已上传的视频添加至其它卡片中。这样您就无需再次等待视频下载完毕了。

    所有视频在发布之前都将经过审核。如果视频违反我们的要求，那么商品仍将销售，但将会进入 错误 标签页中。

通过XLS模板

什么样的视频适用于卡片

  1. 通过 XLS文件 或在线表格打开模板。

  2. 进入 Ozon视频 标签页并输入视频链接：

    • 如果您的卡片中还没有该视频，那么请输入VK Video, Yandex Disk或Rutube链接。视频将保存在Ozon网站上，买家打开视频的速度将更快。

    • 如果您已经上传过该视频，那么请从另一张卡片中添加。 如何从另外一张卡片中复制视频 。

      如果您想添加多个视频，请将每一个链接都输入在新的一行中。

  3. 请上传XLS文件并保存在线表格。

所有视频在发布之前都将经过审核。如果视频违反我们的要求，那么商品仍将销售，但将会进入 错误 标签页中。

  2. 请添加视频。

如何从其它卡片中复制视频

  1. 前往以下选项卡： 商品 → 商品列表 。

  2. 找到带有合适视频的商品。

  3. 点击 操作 并选择 下载按类目XLS模板 。

  4. 点击弹出窗口中的 打开模板 或 下载模板 。在 下载历史记录 中下载所需的XLS文件，为此点击此处 。

  5. 打开 Ozon.视频 选项卡并复制链接。
