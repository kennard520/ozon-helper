手动添加

更新于 2026-09-07 13:11:33 · 来源 global-help.ozon.com

在个人中心中

在个人中心中添加商品时，您可以选择 仅填写主要特征 或者 填写所有特征 。

了解更多关于填写商品特征的信息

填写主要特征

  1. 请进入 商品 → 添加商品 模块并点击 手动 。

  2. 填写商品名称。 为了让商品卡片通过审核，名称需符合我们的 要求 。

    名称示例：

    • 正确：Apple iPhone X 64GB 智能手机。

    • 错误：最棒的智能手机！iPhone X。

      在 Ozon上的名称显示 区块，您可以查看：

    • 买家在应用程序和网站上看到的商品名称；

    • 命名建议。

      如商品名称是根据主要特征自动生成，我们会展示生成逻辑。
      部分商品类目的名称是自动生成的。无法修改橱窗展示名称。

  3. 选择买家能看到商品的类目。 每个类目有对应的 销售佣金 。
    了解更多关于类目搜索

  4. 选择 创建一个变体 。

  5. 手动填写或生成条形码。如果采用FBP模式销售商品，这是必填项。
    了解更多关于条形码的操作

  6. 填写 货号 。

  7. 请设置价格。您可以指定划线价，即商品之前的销售价格。它应高于最高价格。在商品卡片上，买家会看到划线价、新价格和折扣百分比。

  8. 填写商品包装后 重量和尺寸 。

  9. 上传1-30张商品图片，包含主图（主图会在商品卡片中最先显示）。

    上传前请确认图片符合图片 要求 。

    如需设置主图，将其拖动至首位。 其余图片按希望在网站上展示的顺序排列。

    商品创建后，你也可以通过XLS文件、API或在 商品 → 添加商品 → 属性更新 → 上传图片 模块进行图片上传。

  10. 填写带有 标记的主要特征。

  11. 点击 完成创建 ，检查商品信息。如无误，点击 发送 。

想让商品卡片更吸引买家，点击 填写更多 。 可继续填写附加特征并上传媒体资料。 部分字段会自动带入您先前填写的内容。

  1. 请进入 商品 → 添加商品 模块并点击 手动 。

  2. 选择买家将看到商品的类目。不同类目有不同的 销售佣金 。
    了解更多关于类目搜索

  3. 填写商品名称。 为了让商品卡片通过审核，名称需符合我们的 要求 。

    名称示例：

    • 正确：Apple iPhone X 64GB 智能手机。

    • 错误：最棒的智能手机！iPhone X。

      在 Ozon上的名称显示 区块，您可以查看：

    • 买家在应用程序和网站上看到的商品名称；

    • 命名建议。

    如商品名称是根据主要特征自动生成，我们会展示生成逻辑。
    部分商品类目的名称是自动生成的。无法修改橱窗展示名称。

  4. 选择 创建多个变体 ，将多个商品合并到同一商品卡片。

  5. 填写 货号 。

  6. 请设置价格。您可以指定划线价，即商品之前的销售价格。它应高于最高价格。在商品卡片上，买家会看到划线价、新价格和折扣百分比。

  7. 填写特征。影响商品合并的特征带有 标记。

  8. 点击 下一步 。

  9. 填写变体特征——即商品型号间有差异的参数。 至少有一个变体特征需包含多个值。 变体特征举例：

  • 颜色（几乎所有类目都适用）；

  • 尺码（鞋服类）；

  • 重量（多类目适用）；

  • 每包数量（多类目适用）。

  1. 检查变体表格。您可以：

  • 生成条形码；

  • 修改参数（单独或批量操作）；

  • 删除某个变体。

    点击 下一步 。

    了解更多关于变体表格的操作

想让商品卡片更吸引买家，点击 填写更多 。 可继续填写附加特征并上传媒体资料。 部分字段会自动带入您先前填写的内容。

填写全部特征

步骤 1。填写主要特征

  1. 进入 商品 → 添加商品 模块并点击 手动 。

  2. 点击 填写更多 。


    所有更改会保存在草稿中。您可以在24小时内继续编辑。

  3. 填写商品名称。为了让商品卡片通过审核，名称需符合我们的 要求 。

    名称示例：

    • 正确：Apple iPhone X 64GB 智能手机。

    • 错误：最棒的智能手机！iPhone X。

      在 Ozon上的名称显示 区块，您可以查看：

    • 买家在应用程序和网站上看到的商品名称；

    • 命名建议。

      如果商品名称根据主要特征自动生成，会展示生成逻辑。
      部分类目商品名称为自动生成。 无法修改橱窗展示名称。

  4. 选择买家将看到商品的类目。每个类目有对应的 销售佣金 。

  5. 选择 创建一个变体 。

  6. 手动填写或生成条形码。如果采用FBP模式销售商品，这是必填项。
    了解更多关于条形码的操作

  7. 请填写 货号 。

  8. 请设置价格。您可以指定划线价，即商品之前的销售价格。它应高于最高价格。在商品卡片上，买家会看到划线价、新价格和折扣百分比。

  9. 填写商品包装后 重量和尺寸 。

  10. 点击 下一步 。

步骤2。填写商品特征

特征依赖于类目。建议填写所有特征（即便不是必填），这样可以让商品对买家更有吸引力，也更方便搜索。
了解更多 关于 特征的信息

如果您打算销售：

  • 同一商品的多个变体，如不同颜色或尺码——在 合并为一张卡片 字段为 所有变体填写同一数值。这样它们会合并到一张商品卡片。

关于商品合并的更多信息

  • 一件商品包含多件产品（如三瓶洗发水一包）——在 一个商品中的件数 字段填写所含数量。

  • 散卖商品——在 一个商品中的件数 字段填写“1”。

  • “电子产品”类商品——填写部件号。这是制造商分配的编号。 通常印在商品或包装上。

  • 无保质期商品——可留空 保质期（天） 。如为必填，请填写“1000”。

  • 配件商品（如手机配件、汽车配件）——在 配套特征 模块的 适用于什么 区块填写适配品牌、型号及版本。
    关于填写配件和零件销售卡片的更多信息

步骤 3。上传商品图片和视频

需上传至少一张图片才能创建商品卡片。除“汽车用品”、“运动与休闲”、“建筑和装修”外，其它类目必须先上传图片才能上架。在其他类目中，无图片的商品卡片将无法上架销售。

如何添加无图片商品
