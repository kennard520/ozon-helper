条形码上传

更新于 2026-09-02 13:15:06 · 来源 global-help.ozon.com

在模式下销售商品时，所有商品必须有条形码。您可以使用：

  • 您的条形码，例如制造商提供的条形码；

  • Ozon 生成的唯一条形码，可在个人中心中生成，或在创建首批入库交货时生成。

条形码要求

添加条形码的规则：

  • 在同一个SellerID账户中，不同商品必须使用不同的条形码；

  • 在不同的SellerID中，商品的条形码可以相同。

Ozon支持以下格式的条形码：

  • EAN-8;

  • EAN-13;

  • EAN-14 (GTIN-14);

  • ISBN-10;

  • ISBN-12;

  • UPC-12;

  • Code 39 ——仅允许编码以下字符：大写拉丁字母（A至Z）、数字（0至9）、特殊字符：- . $ / + % 和空格。

请勿在条形码开头使用以下字母组合：BP、BX、BXDC、CB、CL、OZN、II、PL、PLDC、SC、SR、US。系统可能无法正确处理这些条形码。

为什么需要条形码

从合作伙伴仓库销售（FBP）时，我们在仓库按条形码验收商品，因此：

  • 没有条形码的商品无法添加到交货请求中；

  • 如果商品上的条形码与个人中心中的条形码不同，FBP仓库将不予验收。部分合作伙伴提供付费重新贴标服务——打印带有正确条形码的标签。如果没有此项服务，则需要将商品取回。

从自有仓库销售（rFBS）时，承运商可以接收没有条形码的商品，并按货件标签将其配送给客户。如果该标签损坏或丢失，条形码可以帮助识别商品。

如果在创建订单时商品卡片中未填写条形码，在Ozon物流环节丢失时我们将无法支付赔偿。该规则自2026年3月17日起生效。

在个人中心添加条形码

请打开 商品 → 添加商品 部分并点击 更新条形码 ，手动或通过XLS模板可以：

  • 在上传商品时填写或生成条形码；

  • 在更新已上传的商品时添加新的条形码。

一个商品最多可以有100个条形码。

为所有商品添加条形码

  1. 进入 商品 → 添加商品 → 属性合并 → 更新条形码 页面。

  2. 选择 无条形码 选项卡。

  3. 您可以选择以下方式添加条形码：

    • 批量自动生成条形码 — 点击 为所有商品生成 并确认操作；

    • 手动输入条形码 — 点击商品行中的 添加 按钮。

针对单个商品

如果您想为单个商品添加或生成条形码：

  1. 请前往 商品 → 添加商品 页面并点击 更新条形码 。

  2. 在 条形码 列中点击：

    • 添加 按钮——如果没有条形码；

    • 条形码本身——如果您想修改它。

  3. 请添加一个或多个条形码：

    • 如果您已有条形码，请填写它——要再添加一个，请点击 ；

    • 如果没有——请点击 生成 ，让系统创建唯一的条形码。
      条形码的生成方式

    一个商品最多可以添加100个条形码。

  4. 请检查：已输入的条形码显示在下方。如果一切正确，请点击 保存 。

通过XLS文件

  1. 请前往 商品 → 添加商品 页面并点击 更新条形码 。

  2. 请点击 更多 ，选择 以XLS格式下载 ，然后打开下载的文件。

  3. 请选择需要执行的操作：

    • 要生成条形码，请在 生成条形码 字段中填写“是”。
      条形码的生成方式

    • 要手动填写条形码，请在 手动输入条形码 字段中输入。如果您想为同一个商品添加多个条形码，请复制并粘贴该商品所在的行。每行填写一个条形码。

  4. 请在个人中心点击 上传条形码 并上传填写好的文件。

如果您添加自己的条形码

系统会对其进行自动检查。我们会用颜色显示结果：

  • 黑色——条形码已通过检查，商品准备销售；

  • 灰色——条形码正在检查中；

  • 红色——条形码无法使用，原因是：

    • 该条形码已用于您的其他商品；

    • 未找到对应的SKU ID——例如，如果您手动添加条形码时在OZN后填写了错误的Ozon SKU ID。

要查看条形码未通过检查的原因，请打开 商品 → 添加商品 页面并点击 更新条形码 ，或打开 商品 → 商品列表 ：

  • 请将光标悬停在红色条形码上；

  • 请切换到 有错误 选项卡——原因会显示在“错误描述”字段中。
    关于条形码操作错误的更多信息

在创建交货时添加条形码

  1. 进入 创建交货申请 页面，选择存储仓库，并添加需要入库的商品。

  2. 如果商品没有条形码，系统会提示错误。系统提示中将显示原因说明及添加条形码的链接。

生成条形码

系统为每个商品生成一个唯一条形码。格式由 OZN 和商品的 Ozon SKU ID 组成。

条形码、货号和Ozon ID有什么区别

示例 ：Ozon SKU ID 为 1234567891。系统生成的条形码为 OZN1234567891。

条形码的生成需要一定时间。完成后，格式 OZNXXXXXXXXXX 中的X将被替换为生成的数字。

查看商品条形码列表

进入 商品 → 添加商品 → 属性合并 → 更新条形码 或 商品 → 商品列表 页面，点击条形码，即可查看该商品的条形码列表。它们按状态分组：

  • 验证中 ——条形码尚未通过检查；

  • 有效 ——条形码已通过检查，可用于销售；

  • 未通过审核 ——条形码不能用于销售商品。

删除和更改条形码

处于审核状态或创建时间不超过 48 小时的条形码可以删除或更改：

  1. 进入 商品 → 添加商品 → 属性合并 → 更新条形码 或 商品 → 商品列表 页面。

  2. 找到商品，并点击其条形码。

  3. 在条形码右侧的窗口中，点击 并选择操作。

以下情况下条形码无法编辑或删除：

  • 商品在 FBP 模式 下销售，且库存售罄时间不足 6 个月；

  • 条形码由系统自动生成。例如：OZN32322342。

条形码的组成

如果您的个人中心中绑定了多个有效条形码，仓库将接受商品上的任意一个条形码。

打印出的条形码上会有：

  • 您填写的或由Ozon生成的代码；

  • 商品货号；

  • 商品名称。

下载条形码

  1. 进入 商品 → 添加商品 → 属性合并 → 更新条形码 或 商品 → 商品列表 页面, 在商品行中点击 ， 然后选择 下载PDF 。

  2. 选择打印机类型。 专用标签打印机 — 系统会自动调整条形码尺寸，以适应标签打印机的纸带；普通办公打印机 — 需要指定数量和尺寸，这取决于纸张格式、工厂条形码和商品本身。可选尺寸：

    • 小号：30×20 mm；

    • 中号：43×25 mm；

    • 大号：58×40 mm。

  3. 点击 以PDF格式下载 。打印好的条形码需要粘贴到每件商品上。如果使用普通打印机打印，需要手动剪裁后再粘贴。

粘贴条形码
