商品卡片转移

更新于 2026-06-10 11:32:17 · 来源 global-help.ozon.com

如果您想将商品种类划分给不同的个人中心，那么商品卡片可以与评分、 买家评价 、 关于商品的问题和回答 以及 在搜索中的位置 一起转移。 您无法使用工具仅转移商品的评价和评分——与卡片相关的所有信息是与卡片一同转移的。

该服务免费，但接收方个人中心的余额必须不低于 0。

符合下列条件的个人中心可以参加转移：

  • 个人中心属于非俄罗斯的卖家或公司；

  • 个人中心仅注册在一个法人身份下，而非自雇人士身份。

您可以有多个活跃的个人中心，但这些个人中心必须注册在同一法人实体下。

转移卡片

您可以转移位于个人中心 商品 → 商品列表 部分 销售中 和 准备销售 选项卡上的商品卡片。

您只能转移接收方个人中心中可上传的商品数量。在创建申请前，请确保剩余限额足以用来转移。无法转移已下架商品、归档商品或有错误的商品。

只有拥有“主管”角色的个人中心用户才能创建商品卡片转移申请。

有关角色的更多信息

步骤1，填写申请并附加文件

在个人中心中只能有一个处于活跃状态的转移申请。如果您忘了向申请中添加一些商品，那么请将其取消并创建新申请，或等待Ozon根据第一个申请完成卡片转移后再创建带有所缺少商品的新申请。

  1. 在个人中心进入 商品 → 商品卡片管理 部分。

  2. 在 商品卡片转移 板块点击 创建申请 。

  3. 选择 转移原因 。这将决定您需要附加的文件列表。

  4. 输入您想要将卡片转移到其中的个人中心的Seller ID。您可以在新个人中心的 设置 → API 密钥 部分找到Seller ID。

  5. 点击 下一步 。

  6. 上传文件。

  7. 点击 创建 。

申请处理可能最多需要5天时间。

步骤2，为卡片转移做好准备

  • 关闭商品推广——您将需要在新个人中心中将其重新开启。
    有关搜索结果推广的更多信息

  • 如果您转移的是品牌商品卡片或封闭类目商品卡片，请将确认文件上传至新的个人中心：

    • 针对封闭类目访问权限 ;

    • 针对品牌商品销售 。

  • 选择要使用的商品卡片，并将其在旧个人中心中的副本归档。

步骤3，选择要转移的商品

当您在 商品 → 商品卡片管理 部分的申请状态转为 可以转移 时，您将可以选择要转移的商品。

  1. 点击 选择商品 。

  2. 选择商品。您可以一次性转移所有商品卡片，也可以通过编辑列表中的筛选条件选择部分商品。您也可以逐个选择商品进行转移，但每次不能超过200件商品。达到限制时，您会在个人中心中看到通知。商品数量不应超过接收方个人中心中允许的卡片上传限额。

步骤4，请检查并转移商品

  1. 转移前请检查商品卡片上的错误。为此，请点击 检查 或从列表中选择商品后点击 检查已选项目 。检查需要时间，您可以在 状态 列中监控结果：

    • “正在检查中”—商品卡片处于审核中。

    • “无错误”—商品卡片中未发现错误。

    • “有错误”—发现错误。—旦出现严重错误，商品将无法转移。

      如果系统检测到错误，您可以：

    • 下载错误报告。 为此，请转到 错误 选项卡并点击 下载XLS格式的错误报告 。

    • 修正错误。 请在商品行中点击 并选择 编辑商品 。在打开的 商品编辑 窗口中修正错误，保存更改并等待审核结束。 了解更多关于商品编辑的信息

    • 将该商品从转移列表中移除。 请在商品行中点击 并选择 删除 。

  2. 完成修改后，请再次发送审核：点击 重新检查 。

  3. 请点击 转移 。

步骤5，请在新的个人中心等待申请批准

在转移时，商品无需通过Ozon审核，这是因为它们是已经过验证的商品的副本。

新个人中心的主管可以批准或拒绝转移申请。 申请获批后，Ozon 将开始转移商品。 过程最多可能需要 5 天。

步骤6，检查转移过程中的错误

要查看商品卡片转移过程中的错误，请进入 商品 → 商品卡片管理 标签页。在 商品卡片转移 → 已发出的请求 模块中找到申请并点击 → 下载XLS报告 。如果没有错误，您将无法下载报告。

某些错误可以在转移开始后的72小时内修正。如果未能及时修正，请创建新的转移申请并添加已修正的商品。

关于转移错误的详细信息

在Ozon将所有商品转移至新个人中心后，我们将在旧个人中心中将商品下架，并转移至 档案 选项卡上。您将无法再使用这些卡片。

Ozon将转移您商品的工厂条形码。在我们系统中生成的代码将无法被转移——在转移之后，您需要重新创建代码并将其贴在包装上。

接受卡片转移申请

那些将出现在您个人中心的商品的评级将影响 卖家评级 。
有关转移影响的更多信息

  1. 进入 商品 → 商品卡片管理 部分。 卡片转移申请位于 商品卡片转移 → 收到的申请 部分中。

  2. 点击 转到申请 查看申请详情。

  3. 对申请做出决定：点击 接受 或 拒绝 。如果您拒绝申请，那么您将无法取消这一决定。将商品卡片转出的个人中心主管需要创建新的申请。

在您接收卡片转移申请后，我们将检查接收方个人中心的限额：

  • 如果限额足够，那么所有卡片都将转移，而限额将根据已转移卡片的数量相应减少；

  • 如果限额已用尽，那么我们将拒绝转移；

  • 如果限额不允许转移所有卡片，那么将转移限额允许数量的卡片。

转移影响

您可以在 商品 → 商品卡片管理 → 商品卡片转移 → 转移历史 部分找到转移申请列表。

接收方个人中心中可上传的商品数量将根据已转移卡片的数量相应减少，而在原始个人中心中，已转移商品将被归档。

商品卡片

如果您曾经从您的个人中心转移过卡片：

  • 在 商品 → 商品列表 部分，卡片将进入 档案 选项卡。

  • 在 商品 → 商品卡片管理 → 商品卡片转移 → 转移历史 部分，申请将进入 已转移卡片 状态。您还将看到转移日期。

  • 将无法更改商品的类目和品牌。

  • 官方品牌的商品卡片只能在获得权利人许可后使用。

如果卡片曾经转移到过您的个人中心：

  • 在 商品 → 商品列表 部分，商品将进入 准备销售 和 销售中 选项卡中。

  • 在 商品 → 商品卡片管理 → 商品卡片转移 → 转移历史 部分，申请将进入 已转移卡片 状态。您还将看到转移日期。

如果商品已经出现在您的个人中心，那么您可以补充库存并开始销售。 评价、评分、评论、在搜索中的位置、问题和回答的转移可能最多需要5天。

销售

具体商品的评级和卖家评级会影响销售。如果您向其转移商品的个人中心的评级低，那么销售可能会下降。 有关卖家评级的更多信息 。

为了让商品更好地销售，您可以开启付费推广。 有关商品推广的更多信息 。

品牌中心

将商品卡片转移至新个人中心不会对您的品牌中心运行产生影响。

商品退货

请在与Ozon解约之前提取退货。解约后您将无法提取退货。

卡片转移不会对提取退货的可能性产生影响：如果在退货刚刚到达仓库时，商品卡片已经在另一个个人中心中，那么您可以提取商品。

对买家的影响

商品卡片转移后将被隐藏，因此这些商品将从用户的 收藏夹 、 在购物车中 、 购买记录 以及商品订阅中消失。

若旧个人中心已被删除，商品将从收藏夹中移除。

若旧个人中心仍处于活跃状态，商品仍保留在收藏夹中，但会显示为“无存货”。代替卡片，我们将显示 该商品已售罄 页面，并附上新店铺的商品链接。

促销码和积分需要在转移完成后，由新个人中心重新发放给买家。
