品牌

更新于 2026-06-04 09:38:11 · 来源 global-help.ozon.com

在向 Ozon 上传商品时请在名称和 品牌 特征中指出其品牌。这可以让商品：

  • 在 Ozon 搜索结果中位置更靠前；

  • 进入网站和应用中的品牌筛选器；

  • 获取来自买家的更多信任。

检查品牌是否存在

请在 商品 → 品牌文件 部分填写 品牌名称 字段。如果列表中没有该品牌，请提交申请创建品牌。

指出品牌

品牌应在 上传商品 时在以下列方式指出：

  • 在个人中心；

  • 通过模板。

在上传一些商品时需要可以证明您有权销售品牌商品的文件。 如果您要上传这样的商品，请首先添加品牌证书。

有关品牌证书及其上传的详细信息

在个人中心

在页面 添加商品 的 特征 标签页中添加商品品牌。在 品牌 字段中填写名称并在列表中选择所需的品牌。如果几个品牌的名称相同，那么请根据下拉菜单中的商标图案或商品类目选择您的品牌：

  • 如果您有多个商品，请在创建时为每个商品都指出其品牌。

  • 如果您没有找到您所需要的品牌，请 申请 添加新的品牌。

  • 如果您的商品没有品牌，那么请选择 无品牌 一值。

通过模板

如果您通过模板上传商品，那么请在模板中为每件商品指出品牌。品牌将在商品卡片的名称中显示。如果您的商品没有品牌，那么请输入 没有品牌 。

有关模板的详细信息

向 Ozon 添加新品牌

如果您想提交新品牌添加申请：

  1. 请进入 商品 → 品牌 部分。

  2. 在右上角点击 添加 → 品牌 。

  3. 在 品牌添加 窗口中：

    • 指出品牌名称；

    • 选择品牌商品将在其中销售的一个或多个类目；

    • 上传商标图案——如果没有商标图案，那么请跳过该字段；

    • 添加商品照片——在照片上需要看得见商标图案和品牌名称；

    • 如需要请为审核人员留下评论。

  4. 点击 发送 。

审核人员将在七个工作日内对信息进行审核。 您可以在 通知 板块的屏幕右上角点击 来查看审核结果。

对名称和商标图案的要求

品牌名称

请指出您所销售产品的商品名称。

如果商标图案中包含品牌，那么它应与品牌的名称完全相符——同样的文字顺序、字母、符号及空格。

下列名称无法添加：

  • 以所有权类型开始的名称：个体工商户，有限责任公司，封闭式股份公司，公众公司，股份公司，股份有限公司，非公有制股份公司；

  • 包含城市名称、邮政地址或网址的名称；

  • 包含淫秽或违禁语言的名称。

在下列情况下 Ozon 可能会要求您提供额外的文件：

  • 品牌与流行品牌读音相同。如 Apply，Appl；

  • 您添加的是带有“Perfume”、“New”、“Collection”字样或商品类型的流行化妆品或香水品牌，如Lacoste Perfume 或Yves Rocher Soap；

  • 名称中包括下列符号：" « » @ # ~ * $ % ( ) + =.

品牌商标图案

商标将显示在Ozon网站上和应用中：

  • 在商品卡片上；

  • 在筛选器板块中；

  • 在品牌货架上。

商标的尺寸和比例将根据它位于的部分而有所不同。

请添加一个小图案——它将在品牌页面和商品卡片中显示。 如果您有商标的多个版本，请使用浅色或白色背景的版本。

对图片的要求：

  • 格式——JPG, JPEG 或 PNG；

  • 尺寸——不大于5 MB；

  • 分辨率——不低于500 × 500像素。

该商标可以放置于第三方网站上，包括文件托管网站在内，如Yandex.Disk。不要使用Google Disk或Dropbox。

如果商标图案中包含品牌，那么它应与品牌的名称完全相符——同样的文字顺序、字母、符号及空格。

请使用商标的图像和文字部分。如果商标为买家熟知，您可以仅留下图像部分。

商标生成建议：

  • 请不要使用低质量的图片或者商品或招牌上的商标。商标应平整且完全可见。

正确 不正确

  • 不要在商标附近留下多余的空间。

正确 不正确

  • 请不要使用两边比例为2:1的正方形或横向商标。

正确 不正确

  • 请不要使用小细节：题词、网站地址或邮箱。小细节将在被缩小时无法辨认。

正确 不正确

品牌类目

每个品牌都分配有自己的一组商品类目。如果您选择正确，那么在添加商品时将更容易找到品牌。

可以指出总类目——如“日化”；也可以具体类目——比如“洗涤用品”。

品牌商品照片

在添加品牌时我们将要求您提供所选类目的商品照片。请上传1-2张图片：

  • 照片中应呈现在包装中的商品以及不带包装的商品；

  • 在商品上应可以看到品牌名称和/或商标图案；

  • 针对“服装”类目：必须可以看到带有品牌名称和/或商标图案的标签。

在下列情况下照片不合格：

  • 照片在图形编辑器中处理过——比如几张照片的拼贴图或在图片上有标注字样；

  • 商品上没有名称或品牌商标图案。

添加或更改品牌详情

请与 客服 取得联系：

  1. 选择请求的主题 商品和价格 → 商品卡片 → 创建/更改品牌 。

  2. 输入您想添加的品牌名称和详情。

请不要在品牌详情中添加链接。

客服将把详情添加至品牌页面——该页面可以通过品牌目录或商品卡片进入。

详情示例：

如果新品牌申请被拒绝了

  1. 请进入 商品 → 品牌 部分并打开您的申请。 我们将在 审核人员评论 和 结果 字段中指出拒绝的原因以及完善申请的建议。

  2. 请创建新的申请——请充分考虑审核人员的评论来填写申请字段，并在 审核评论 字段填写您做出了哪些修改。

如果审核人员请您提供商标证书或联邦工业产权局的凭证，请将文件的复印件发送给 客服 ： 商品和价格 → 商品卡片 → 创建/更改品牌 。

更改品牌名称、商标图案或商品类目

请写信给 客服 ： 商品和价格 → 商品卡片 → 创建/更改品牌 。

请在请求中指出：

  • 当前名称和新名称。

  • 品牌商品的销售类目。

  • 品牌商品图案：

    • 格式 — PNG, JPG 或 JPEG；

    • 尺寸 — 200 × 200 像素，不大于 5 MB。

    • 如果商标图案中包含品牌，那么它应与新品牌的名称完全相符。

  • 带有新名称的商品照片或包装照片。

  • 如果品牌已注册，那么需要联邦工业产权局的凭证。

请在请求中指出：

  • 品牌名称。

  • 品牌商品的销售类目。
