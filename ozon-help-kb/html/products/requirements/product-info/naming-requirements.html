商品标题

更新于 2026-06-02 09:22:41 · 来源 global-help.ozon.com

您可以用以下方式来命名商品标题：

自动 手动
对于 服装和鞋类 类目，名称会根据商品的必填特征自动生成，格式为 类型 + 品牌 + 服装和鞋类系列 。

对于其他所有类目，名称会根据商品的必填特征自动生成，格式为 品牌 + 类型 + 型号 + 该商品类目的重要特征 。

自动生成标题的类别		 您可以自行指定将显示在网站上的名称，但名称必须符合 要求 。

请按以下格式填写名称： 品牌 + 类型 + 型号 + 该商品类目的重要特征 。

各类目命名的建议

我们进行了调查并根据所获取的数据制定了名称模板，这些模板有下列特点：

  • 商品在 Ozon、Yandex 和 Google 搜索结果中的排名会更靠前，买家也更容易找到。

  • 标题中将包含重要特征，买家会更快地意识到这是什么产品。

  • 广告系统将更容易识别潜在买家，并向他们展示您的报价。

  • 版主将不太可能因为错误的标题而拒绝产品卡。

不同类目的模板名称示例：

类目 模板 标题
电子 品牌 + 类型 + 型号名称 + 重要特征 Razer Клавиатура беспроводная BlackWidow V3 Mini, (Razer Yellow), черный
运动与休闲 品牌 + 类型 + 重要特征 Adidas Футбольный мяч, 5 размер, белый
宠物用品 品牌 + 类型 + 重要特征 Catsan Наполнитель Минеральный Впитывающий 4900 грамм
服装和鞋子 类型 + 品牌 + 服装和鞋类系列 Кроссовки Nike Air Force 1

商品完整名称显示示例：“DeLonghi 电热水壶 KBOV2001.BG，奶油色”：

系统会自动为指定的类别生成商品名称，而不管 名称 字段如何填写。

  • 汽车用品，

  • 医药保健，

  • 家用电器，

  • 电子游戏，

  • 服饰用品和配饰，

  • 居家生活，

  • 印刷书籍，

  • 美容与健康，

  • 家具，

  • 音乐，

  • 维修与施工，

  • 运动与休闲，

  • 珠宝饰品，

  • 电子产品。

总体建议

商品名称中的商品类型应与所选类型一致。 请不要在名称中填写过多特征，只保留最重要的特征。

请按以下格式填写名称： 品牌或制造商 + 商品类型 + 商品名称 ：

  • 品牌或制造商 — 如有请填写；

  • 商品类型 — 商品是什么；

  • 商品名称 — 您的商品名称及重要特征（如有）。

例子：

正确 错误
First Puzzle (品牌) пазл для малышей (类型) "Енотик" , 9 элементов (您的名称) • First Puzzle "Енотик", 9 элементов — 缺少类型，买家不知道是什么商品。
• Пазл для малышей "Енотик" — 未填写品牌和重要特征。
• Конструктор из бумаги First Puzzle "Енотик", игры для самых маленьких, развивающие игры 3+ — 类型错误，存在过多同义词。

商品名称应该是什么样子的

对名称的要求 说明
应指出商品相关类型 比如：娃娃，柜子，智能手机，垃圾桶（“书籍”类目除外）
应以大写字母开头 比如：台座，水杯
应由允许的字符组成 可以使用:
- 俄语和英语字母。
- 数字。
- 符号： . , : ; ( ) - / & "。
- 感叹号和问号，如果没有它们名称将不正确（比如，如果感叹号是书籍名称的一部分）。
不能包含禁用符号 不能使用下列符号：
- 商标 ™。
- 版权标识 ©。
- 注册商标 ®。
- [ ] , = , \ , «‎ » 。‎
系统会自动将不符合要求的符号替换为空格。
最大长度 一个词——27个字符。
整个名称——200个字符。
在长名称中必须要包含所有的标点符号 请用以下符号来分割名称：. , "" /
名称应是语法通顺的句子，而不是由主格和初始形式拼成的一组词语 审核人员将不会批准名称为“娃娃女孩玩具儿童塑料”的商品
不能包含两个以上单根词 型号列举除外
不含广告等不必要的信息 如果名称中包含下列内容，我们将不会批准该商品：
- “促销”、“大甩卖”、“折扣”以及“只有今天”字眼；
- 商品价格；
- “最佳商品”、“独特商品”、“惊艳商品”等类似字眼；
- “类似”、“仿制品”、“翻版“、”copy“、”复制品“、”1：1“、“基于”、“原版”、“original”、“正品”字眼。
不能包含音译词语（“书籍”类目除外）或大写字母。
例外情况：允许使用缩写，如GOST或生产商使用的名称，如SEGA。		 如果名称中有大写字母拼成的词语，如“KUKLA[ 娃娃]，ADAPTER[ 充电器 ]”，那么审核人员将不会批准该商品。
不能包含隐藏的格式字符 您可以使用 专门服务 来找到隐藏的字符。请从已填写好的卡片中复制名称来进行检查——系统将把 Ozon 卡片上看不到的隐藏词语用藕荷色突出显示。
为了避免隐藏字符的出现，请手动编辑商品名称。
不能包含搜索同义词。在 Ozon 搜索算法中已经考虑到了所有的搜索同义词，因此在商品名称中额外使用这些词反倒会使商品在搜索结果中的位置下降。 比如说，这样的名称就是不合适的：“镜子壁式镜子浴室镜子走廊镜子化妆镜子大镜子”
不能包含其它来源的链接或引用 比如：“请在小册子中查看更多信息”
不能包含不间断的空格 禁止将位于其后的词语移动至新的一行的特殊符号。 它们在文章中是这样的： & n b s p ;
不能包含HTML 标记 用来生成网页内容的特殊符号：< p >, < a >, < b >
