对图片的要求

更新于 2026-06-02 09:20:41 · 来源 global-help.ozon.com

商品照片

参数 要求
格式 JPEG, JPG, PNG, HEIC, WEBP。
分辨率 针对 服装、鞋子和配饰 类目——最低900 × 1200像素。
针对其他类目——从200 × 200到4320 × 7680像素。
横纵比 所有类目均采用竖版3 : 4图片。
大小 不超过10兆。

请上传比例正确的照片，以最佳效果展示商品。若主图宽高比不符合3 : 4，那么我们将采用8点拉伸法适配，或者主图将带有上下空白区域进行展示。

您还可以使用 照片编辑器 中的“3х4裁剪”工具。

关于照片编辑的更多信息

如何向商品卡片上传照片

不可以使用:

  • 酒类图片;

  • 商品草图，比如3D模型;

  • 黑白照片；

  • 模糊的、不清晰的和质量不好的照片；

  • 在家里拍摄的照片：以地毯和带有其它物品阴影的家具为背景的照片；

  • 下列文字:

    • 带有价格、折扣、联系方式和社交网站的文字；

    • 价值判断，比如“热销”、“最佳”、“领先者”和“热门”；

    • 带有已售商品数量的文字，比如“已销售 100 件”。

  • 不包含您商品的照片；

  • 未经其他卖家同意上传其商品照片；

  • 展示暴力或煽动仇恨的禁止内容。

对18+ 商品照片要求

该要求适用于商品的所有照片：主要图片以及附加图片。

必须以模糊或以其它方式隐藏处理身体私密部位。比如生殖器官、女性胸部、臀部图片以及模仿生殖器的玩具的图片，该要求适用于商品照片、模特以及包装上的图片。

主要图片

对照片的要求

  • 主要图片的数量为一张。

  • 照片应与商品名称和描述相符。

  • 商品应完整展示在图片上。通过图片即可了解商品在使用时的外观。比如说，如果商品为床上用品，那么请上传它铺在床上的照片，而不是在包装中的照片。

  • 照片应为彩色照片，且质量良好。

  • 照片清晰，商品位于焦点处。

  • 照片上没有水印。

  • 可以使用 信息图表 。

对链接的要求

上传主要照片时，您只能添加一个直接链接。

通过链接应该仅打开和下载图片。通常，此类链接以 .jpeg、 .jpg、* .png结尾。

只有 Yandex.Disk 链接除外——它们的格式为 https://yadi.sk/i/qUXcCwzmryWINw 或 https://disk.yandex.ru/i/qUXcCwzmryWINw

正确的链接：

  • 不会通向带有图片的 HTML 页面。例如，不能输入通向带有照片的商品简介的链接；

  • 不需要授权即可访问图片。

附加图片

为了让买家更频繁地将您的商品添加至购物车，我们建议您上传至少两张附加图片。

对图片的要求

  • 附加图片的数量不应超过29张。

  • 如果食品的商品描述中没有成分表，那么请添加带有成分表的附加图片。

  • 图片应符合商品名称和描述。

  • 照片上没有水印。

  • 可以使用 信息图 。

针对一些商品可添加模特照片或商品在室内的照片：

  • 针对服装可添加服装在模特身上的照片。适用于主要图片和附加图片。

  • 针对家具、床上用品、桌布和窗帘可添加其在室内的照片。适用于主要图片和附加图片。

  • 针对食品可添加其在室内的照片。只适用于附加图片。

对链接的要求

图片直接链接

如果您分别上传照片，则请分别为每个图片添加一个链接。 上传数量限制为29张。请使用空格、分号、逗号或换行符来分隔链接。

通过链接应只能打开和下载图片。通常，此类链接以 .jpeg、 .jpg、* .png结尾。

只有 Yandex.Disk 链接除外——它们的格式为 https://yadi.sk/i/qUXcCwzmryWINw 或 https://disk.yandex.ru/i/qUXcCwzmryWINw 。

正确的链接：

  • 不会通向带有图片的 HTML 页面。例如，不能输入通向带有照片的商品简介的链接；

  • 不需要授权即可访问图像。

图片文件夹的链接

可以使用 Yandex.Disk 图片文件夹的链接。比如 https://yadi.sk/d/qUXcCwzmryWINw 或https://disk.yandex.ru/d/qUXcCwzmryWINw。

文件夹中的29张图片将被作为附加图片使用。如果您想让图片根据一定的顺序上传，请在名称中添加数字。如 "1"，"2"，"3" 或 "商品 1"，"商品 2"，"商品 3"。

信息图表

信息图表是一种图像。在这种图像上，您可以通过令人印象深刻的形象或简单的示意图来直观地对商品进行讲述。比如展示主要特点、优势和成分。

与文字描述不同，图表可以立刻吸引买家的注意并且更容易让人记住。在制作图表时可以使用品牌特有的颜色和元素。

有效的信息图表应包括下列内容：

  • 属性：商品参数。

  • 益处：为什么买家应该选择该商品。

  • 优势：独特特点。

推荐的服务

建议使用具有高带宽和地理分布的内容分发网络（CDN）服务来存储图片。 这样可以加快图片在平台上的上传速度，并提升商品创建流程的效率。

推荐使用以下服务：

  • alicdn.com （阿里云 Alibaba cloud）；

  • yandexcloud.net （Yandex 云）；

  • aliyuncs.com （阿里云 Alibaba cloud）；

  • myqcloud.com （腾讯云 Tencent cloud）；

  • amazonaws.com （亚马逊云 AWS / Amazon cloud）。

如何获取照片的直接链接

请不要向Google Drive或Dropbox上传图片——在这些网站上无法获取直接链接。我们建议您使用Yandex.Disk。

通过Yandex.Disk
