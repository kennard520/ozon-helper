## 商品状态

要在Ozon上发售商品，请完成以下步骤：

- 设定价格。

- 更新仓库库存。

- 等待审核结果（1～3天）。

商品状态显示在
[商品→商品列表](https://seller.ozon.ru/app/products?filter=all)
 页面上。

商品状态会显示商品是否已通过审核，并包括以下组成部分：

- **主要状态**
，通过颜色可了解审核结果：

绿色 —
 商品卡片已通过审核，可以销售。
黄色 —
 存在非关键性问题。商品可以销售，但由于错误，商品卡片在竞争中排名较低。
红色 —
 商品未通过审核。存在关键性错误，无法创建或更新商品卡片。
**附加状态**
（对商品主要状态的进一步解释）。

| 主要状态 | 附加状态 | 可见性 | 说明 |
| --- | --- | --- | --- |
| 在售中 | - | 是 | 商品可以在Ozon上购买。 |
| 在售中 | 正在更新 | 是 | 您编辑了商品信息，我们正在审核所作出的更改。在此情况下，Ozon上显示的是未更改的商品信息页，买家可购买该商品。 |
| 在售中 | 未更新 | 是 | 您编辑了商品信息，但我们无法应用更改。在此情况下，Ozon上显示的是未更改的商品信息页，买家可购买该商品。 |
| 准备出售 | 无存货 | 否 | 商品缺货，无法在Ozon上购买。请注明该商品的库存数量。 |
| 准备出售 | 您关闭了可见性 | 否 | 您关闭了商品可见性，买家无法在Ozon上购买该商品。 |
| 未出售 | 在创建中 | 否 | Ozon上尚未创建这件商品，现在还无法购买。 |
| 未出售 | 在审核中 | 否 | 您编辑了商品信息或创建了新商品。我们正在审核所作出的更改（通常需要1
 ～3天）。商品还无法在Ozon上购买。 |
| 未出售 | 未创建 | 否 | 无法创建具有这些规格的商品。请确认您是否已正确注明商品规格。商品还无法在Ozon上购买。 |
| 未出售 | 未通过审核 | 否 | 您编辑了商品信息或创建了新商品。我们已检查您所作出的更改并发现了错误。请改正错误并再次保存更改，我们随后会再次审核商品。现在还无法在Ozon上购买这件商品。 |
| 未出售 | 被屏蔽（FBS屏蔽原因） | 否 | 该商品被屏蔽，无法在Ozon上购买。 |

## 仓库中的商品可售数量

要查看有关商品库存数量的详细信息，请在
[商品→商品列表](https://seller.ozon.ru/app/products?filter=all)
 页面将鼠标悬停在所需商品的数量值上方：

![](../../../images/ac4ba08c965fd08c.png)

商品各状态的意义如下：

**可售数量**
：可以在Ozon上购买的数量，包括降价商品。

- **其中降价商品数量**
：可以在Ozon上购买的降价商品数量。该状态对外国卖家不可用。

- **预定商品数量**
：买家预定的商品数量。从在Ozon收到订单起，直到将货物包装发货给买家为止，货物都被视为预定商品。

- **商品总数**
：商品的库存总数。
