## 总体建议

> > 商品名称中的商品类型应与所选类型一致。
> 请不要在名称中填写过多特征，只保留最重要的特征。
>

请按以下格式填写名称：
**品牌或制造商**
 +
**商品类型**
 +
**商品名称**
：

- 品牌或制造商 —
 如有请填写；

- 商品类型 —
 商品是什么；

- 商品名称 —
 您的商品名称及重要特征（如有）。

例子：

| 正确 | 错误 |
| --- | --- |
| **First Puzzle**

**пазл для малышей**
 (类型)
**"Енотик"**
,
**9 элементов**

(您的名称) | •
**First Puzzle "Енотик", 9 элементов**
 — 缺少类型，买家不知道是什么商品。

•
**Пазл для малышей "Енотик"**

### 商品名称应该是什么样子的

| 对名称的要求 | 说明 |
| --- | --- |
| 应指出商品相关类型 | 比如：娃娃，柜子，智能手机，垃圾桶（“书籍”类目除外） |
| 应以大写字母开头 | 比如：台座，水杯 |
| 应由允许的字符组成 | 可以使用:

 - 俄语和英语字母。

 - 数字。

 - 符号： . , : ; ( ) - / & "。

 -
 感叹号和问号，如果没有它们名称将不正确（比如，如果感叹号是书籍名称的一部分）。 |
| 不能包含禁用符号 | 不能使用下列符号：

 - 商标 ™。

 - 版权标识 ©。

 - 注册商标 ®。

 - [
 ] , = , \ , «‎ » 。‎

 系统会自动将不符合要求的符号替换为空格。 |
| 最大长度 | 一个词——27个字符。

 整个名称——200个字符。 |
| 在长名称中必须要包含所有的标点符号 | 请用以下符号来分割名称：. , ""
 / |
| 名称应是语法通顺的句子，而不是由主格和初始形式拼成的一组词语 | 审核人员将不会批准名称为“娃娃女孩玩具儿童塑料”的商品 |
| 不能包含两个以上单根词 | 型号列举除外 |
| 不含广告等不必要的信息 | 如果名称中包含下列内容，我们将不会批准该商品：

  -  “促销”、“大甩卖”、“折扣”以及“只有今天”字眼；

 - 商品价格；

 -  “最佳商品”、“独特商品”、“惊艳商品”等类似字眼；

 -
 “类似”、“仿制品”、“翻版“、”copy“、”复制品“、”1：1“、“基于”、“原版”、“original”、“正品”字眼。 |
| 不能包含音译词语（“书籍”类目除外）或大写字母。

 例外情况：允许使用缩写，如GOST或生产商使用的名称，如SEGA。 | 如果名称中有大写字母拼成的词语，如“KUKLA[
娃娃]，ADAPTER[
充电器
]”，那么审核人员将不会批准该商品。 |
| 不能包含隐藏的格式字符 | 您可以使用
[专门服务](https://www.soscisurvey.de/tools/view-chars.php)
来找到隐藏的字符。请从已填写好的卡片中复制名称来进行检查——系统将把 Ozon 卡片上看不到的隐藏词语用藕荷色突出显示。

 为了避免隐藏字符的出现，请手动编辑商品名称。 |
| 不能包含搜索同义词。在 Ozon
 搜索算法中已经考虑到了所有的搜索同义词，因此在商品名称中额外使用这些词反倒会使商品在搜索结果中的位置下降。 | 比如说，这样的名称就是不合适的：“镜子壁式镜子浴室镜子走廊镜子化妆镜子大镜子” |
| 不能包含其它来源的链接或引用 | 比如：“请在小册子中查看更多信息” |
| 不能包含不间断的空格 | 禁止将位于其后的词语移动至新的一行的特殊符号。 它们在文章中是这样的： & n b s p
 ; |
| 不能包含HTML
 标记 | 用来生成网页内容的特殊符号：, ,  |
