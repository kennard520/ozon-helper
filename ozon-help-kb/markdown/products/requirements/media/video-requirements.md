## 视频

### 对视频内容的要求

视频中必须包含它所属的商品——请在视频中展示商品的优点和使用示例。Используйте请使用音质良好的视频。

包含下列内容的视频将无法发布：

- 脏话，侮辱性言辞；

- 酒，烟；

- 下列文字：

带有价格、折扣、联系方式和社交网站的文字；
提及 Instagram 和 Facebook 的文字（它们属于被俄罗斯承认为极端组织且在俄罗斯被禁止的 Meta
 公司）。
物流及退货条件，比如“快速物流”或“明日送到”；
其它平台或商店的广告；
个人信息，如银行卡号码或护照照片；
身体私密部位，色情声音；
俄罗斯法律禁止的信息；
[禁止在 Ozon 上销](/products/requirements/special-categories/)
.售的商品。

### 对视频的技术要求

为了压缩视频，可以使用以下编码译码器： MPEG-1 video, MPEG-2 video, VC-1, H.264, HEVC (H.265), VP8, VP9, MPEG-4, MPEG-4 Part 2, MPEG-4 Part
 3.

| 参数 | 要求 |
| --- | --- |
| 格式 | MP4,
 MOV. |
| 分辨率 | 长边像素为 1080 px至1920
 px。 |
| 大小 | 如从电脑上通过个人中心上传文件——则不得大于 100MB。

在其它情况下——不得大于
 5GB。 |
| 长度 | 从 8 秒至 5
 分钟。 |

### 对视频链接的要求

请仅从 VK Video, Yandex.Disk 或Rutube
 上传视频。

可以添加视频链接或带有文件的文件夹——在文件夹中应只包含视频。

系统无法看到其它格式或子文件夹。下载限制量为 5
 个视频。

如果您想拷贝 Yandex.Disk 中的链接，请选择照片或文件夹并点击
**分享 → 复制链接**
。

请在您的帐户隐私设置中，确保所有用户都可以看到您的视频列表。

- 请在VK视频网站打开视频。

- 请从地址栏复制视频的直接链接。

请复制视频的直接链接：

- 在 Rutube
 网站上打开视频。

- 复制浏览器地址栏中的链接。
