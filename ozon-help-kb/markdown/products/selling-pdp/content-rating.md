内容评级是关于商品数据填写与优化的建议，可帮助商品对买家更具吸引力。评级越高，买家选择您商品的概率越大。

内容评级不保证一定会提升销量。为提升销量，我们建议结合使用其他引流工具，例如促销活动、价格和评价。

[了解更多 Ozon上的搜索运行原理](/analytics/analytics-and-metrics/products-in-search-results/searching-result-impact/)

## 如何查看自己商品的评级

评级分为三个等级：

- 0–39
 分——低；

- 40–79
 分——基础；

- 80–100
 分——高。

用于提升评级的特征列表取决于商品类目。如果某项特征无法填写，请联系客服说明情况。我们会审核您的请求；如果不会影响其他卖家，将把该特征从计算中排除。

较低的内容评级不会导致平台封禁或限制，但会提示您哪些信息值得补充，以帮助买家做出选择。

您可以通过以下方式查看该指标：

- 在
[商品 → 商品列表](https://seller.ozon.ru/app/products)
中。在
**内容评级**
列点击商品对应的数值字段，即可查看评级得分以及提升建议。

![](../../images/fa4ec7cdb509ea33.webp)
在卖家个人中心编辑或创建商品卡片时查看。

![](../../images/bcd4710c67dd09a6.webp)
通过 API——使用方法
[/v1/product/rating-by-sku](https://docs.ozon.ru/api/seller/#operation/ProductAPI_GetProductRatingBySku)
。
在 CSV 报表中——进入
[商品 → 商品列表](https://seller.ozon.ru/app/products)
，点击
**下载模板**
，并选择
**商品CSV**
。

## 如何提升内容评级

如需补充已创建商品的特征信息，请按以下步骤操作：

在
[商品 → 商品列表](https://seller.ozon.ru/app/products)
 中，点击商品在
**内容评级**
列中的数值字段。

- 在弹出的窗口中，我们会显示当前评分，并允许您补全商品缺失的信息。要获得最高评分，需要：

上传媒体素材——8 张图片和 1
 个视频；
填写所需的商品特征；
添加描述。

我们会显示该商品可能获得的评分——评分会根据您已填写的数据量动态变化。

![](../../images/014c0ad4204ac411.webp)
当您补全所有信息后，点击
**保存**
——商品卡片将被提交审核。若审核通过，内容评级将会更新。
请注意：若超过商品卡片可编辑次数限制，将无法提交修改。

在商品卡片处于审核期间，商品列表中的内容评级字段会显示
**正在计算中**
。

审核完成后，该单元格将显示实际得分。

例如，您决定更新商品卡片以提升内容评级。补全商品信息后，我们会显示评分可能从 30.5 提升到
 75。

当您保存商品卡片后，我们会将其提交审核。在审核期间，内容评级仍为 30.5 分。如果审核通过且未发现错误，内容评级将提升至 75
 分。

如果未通过，则会保持原值——30.5
 分。

如您在填写内容评级相关信息时遇到问题，请联系
[客服](https://seller.ozon.ru/app/messenger?channel=SCRM)
。

有时我们会在您已完成商品卡片填写后新增特征项——此时内容评级可能会降低。如需了解新增了哪些属性并提升评级，请进入商品编辑模式或打开内容评级窗口——其中会出现新的未填写特征项。

## 内容评级如何计算

内容评级由商品信息的 3 个部分组成：
[媒体](#媒体45-分)
,
[特征](#特征30-分)
和
[描述](#商品描述25-分)
。

三个部分合计最高可获得 100
 分，每个部分都有各自的最高分值。

评级中不包含必填特征，因为缺少这些信息商品无法通过审核，也不会在平台上展示。

![](../../images/904e644c6009714b.webp)

## 媒体：45
 分

本类别评估所有有助于展示商品的信息：图片和视频。

[了解更多图片要求](/products/requirements/media/image-requirements/)

| 分数 | 条件 |
| --- | --- |
| 45 | 8 张图片 + 1
 个视频 |
| 27 | 8
 张及以上图片 |
| 22.5 | 5–7
 张图片 |
| 18 | 1
 个视频 |
| 13.5 | 3–4
 张图片 |
| 4.5 | 1–2
 张图片 |
| 0 | 无图片和视频 |

例如，您在网站上上传一款地毯。如果您上传 4 张图片和 1 个视频，将获得 31.5 分。如果再添加 2 张图片，评级将提升至 40.5
 分。

## 特征：30
 分

搜索特征可帮助系统对商品进行归类，并通过筛选器和搜索找到商品。

特征数量取决于您的商品类型。

| 分数 | 条件 |
| --- | --- |
| 30 | 填写超过 70%
 的特征 |
| 15 | 填写 50%–70%
 的特征 |
| 7.5 | 填写 15%–50%
 的特征 |
| 0 | 填写不超过 15%
 的特征 |

**示例**
。 您的商品可能包含 9
 个搜索特征。您将获得：

0 分——若填写 0 或 1
 个特征；

- 7.5 分——若填写 2、3 或 4
 个特征；

- 15 分——若填写 5 或 6
 个特征；

- 30 分——若填写 7、8 或 9
 个特征。

## 商品描述：25
 分

商品描述能帮助买家更了解商品并提升信任度。描述越完整，用户越可能从中找到所需信息。评分时按包含空格的字符数计算。

描述中可以添加
[JSON富内容](/products/upload/adding-content/rich-content/)
——多媒体元素，可吸引注意力并突出商品的重要特点。

| 分数 | 条件 |
| --- | --- |
| 25 | 描述为 101–500 个字符（含空格），但没有
[富内容](/products/upload/adding-content/rich-content/) |
| 12.5 | 描述为 501 个及以上字符（含空格），但没有
[富内容](/products/upload/adding-content/rich-content/) |
| 12.5 | 有
[富内容](/products/upload/adding-content/rich-content/) |
| 0 | 描述少于 101 个字符（含空格），且没有
[富内容](/products/upload/adding-content/rich-content/) |

> > 例如，您的商品卡片中有富内容，但没有商品描述，则可获得 12.5 分。如果再添加一段 120 个字符的商品文字说明，则可获得 25
> 分。
>
