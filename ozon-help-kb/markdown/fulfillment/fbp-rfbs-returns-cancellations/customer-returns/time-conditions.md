退货期限取决于商品类目和质量。

| 商品类目 | 质量合格商品的退货期限 | 质量不合格或对订单履约提出投诉时的退货期限 |
| --- | --- | --- |
| 食品。
宠物饲料。 | 不可退货 | 1天 |
| 数字商品。
具有个别确定属性的商品。 | 不可退货 | 7天 |
| 非连续出版物：图书、小册子、画册、地图出版物、乐谱出版物、单张出版物、日历、折页，以及在技术信息载体上复制的出版物。
个人卫生用品：牙刷、梳子、发夹、卷发器、假发、假发髻。
新年商品：人造圣诞树、电子彩灯串、圣诞树装饰品。
长筒袜、袜子、连裤袜、内衣、睡衣。
医疗器械。 | 7天 | 7天 |
| 其他类目的商品。 | 15天 | 15天 |

## 质量合格商品的退货条件

买家可以在以下情况下退货：

- 商品保持原有外观和消费属性；

- 无使用痕迹；

- 原厂包装未损坏；

- 未在电子产品上安装或激活程序；

- 商品未过保质期；

- 买家退回整套商品，例如两卷本图书须退回全部两卷。

需要加注易燃燃料才能运行的商品，只能在燃料箱或燃料瓶已排空的情况下退货。

## 质量不合格商品的退货条件

买家可以在以下情况下退货：

- 送达的商品、尺寸或颜色有误；

- 商品缺少部件；

- 商品已过保质期或在配送过程中损坏；

- 商品为假货；

- 商品无法使用或运行不稳定。

## 保修期内退货

如果您为非技术复杂商品设定了保修期，其退货期限不少于自送达之日起14天。您可以在商品卡片中注明保修期。

技术复杂商品可适用Ozon保修。对于此类商品，买家可在365天内退货，自送达之日起计算。退货时，我们可能会要求买家提供：

- 授权服务中心或专家出具的结论原件，确认商品缺陷属于生产缺陷且为重大缺陷。

[关于授权服务中心的更多信息](https://docs.ozon.ru/common/otmena-i-vozvrat-zakaza/remont-garantijnuh-tovarov/service-centers/)

- 保修卡原件。

在以下情况下，Ozon或卖家可能会要求买家提供补充照片、视频或问题描述：

- 买家所在地没有服务中心；

- 服务中心不接收商品进行检测或维修；

- 买家提供的退货原因信息不足。

如果在检查补充材料时发现商品不符合退货条件，买家将无法退货。
