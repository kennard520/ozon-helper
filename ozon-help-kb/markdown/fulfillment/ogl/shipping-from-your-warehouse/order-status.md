如需了解每个订单处于哪个阶段以及您需要做什么，请在个人中心的
**[物流 → 订单 → OGL和realFBS](https://seller.ozon.ru/app/postings/fbs?tplProviderId=24&tab=awaiting_packaging)**
部分查看订单状态。

| **状态** | **描述** | **操作** |
| --- | --- | --- |
| **等待备货** | 您收到了新订单 | 请将其包装好并确认备货。 |
| **已准备发运** | 订单已完成备货，可以转移配送。 | 请准备好订单，以便自行或由快递员送至Ozon货运代理的分拣中心。 |
| **已准备发运 **
![clock_filled](../../../images/608c6be76268e8da.png) | 集运仓库中未发现该货件。出现这种情况通常是因为您忘记转交订单，或者我们找不到该订单。 | 请在最近一次发运中送来该订单，或将其取消。取消订单会影响您的
[错误指数](https://global-help.ozon.com/zh/ratings/cancellation-percentage)
。
 
[如何处理此状态下的订单](https://global-help.ozon.com/zh/fulfillment/ogl/dispute/disputed-orders) |
| **在运往集运仓库的途中**
**（采用Pick-up发运方法时）** | Ozon货运代理的快递员已接收您的订单，正在运往集运仓库的途中。 | - |
| **正在验收中**
**（采用Self-Drop发运方法时）** | 我们在集运仓库验收订单——拆开货位并检查一切是否正常。这可能需要长达1天的时间。 | - |
| **运输中** | 我们已从集运仓库取走商品，正在运往俄罗斯的分拣中心，之后将其交给快递员或发往买家的取货点。 | - |
| **交给快递员中** | 快递员即将取走订单，并送达买家。 | - |
| **运至取货点途中** | 订单正在运至取货点的途中。订单被接收后，买家将收到订单可领取的通知。 | - |
| **快递员派件中** | 快递员已取走订单，正在送往买家。 | - |
| **已到达取货点，待取件** | 订单已送达取货点，买家可在14天内领取。 | - |
| **已签收** | 买家已在取货点或从快递员处取走订单。 | - |
| **已取消** | 您或买家取消了订单。 | 请查看订单是在哪个阶段被取消的。这有助于您了解下一步该怎么做。
[关于取消的更多信息](https://global-help.ozon.com/zh/fulfillment/fbp-rfbs-returns-cancellations/order-cancellation) |
