如果申请状态变更为
**需要编辑**
，表示仓库因错误拒绝了申请。

要查看哪些商品存在问题以及需要修改的内容：

- 打开申请的草稿，进入
**错误**
 部分。

- 下载错误列表。
请修正错误后，点击
**创建申请**
。

![](../../../../images/eb001fc611a7ace8.png)
如果申请状态保持“需要编辑”超过30天，我们将自动从个人中心中删除该申请。
