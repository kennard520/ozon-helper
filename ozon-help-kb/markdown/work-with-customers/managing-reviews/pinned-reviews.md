置顶评价是一项工具，会为尚未有置顶评价的商品查找并置顶合适的评价。

如果您认为某条评价对买家有帮助，可以手动将其置顶。

[如何置顶评价](#置顶评价)

该工具在订阅有效期内可用。订阅关闭后，我们会取消置顶评价。订阅恢复后，我们会重新置顶此前的评价，或置顶新的合适评价。

系统会将满足以下条件的评价视为有帮助：评分为5星，且长度不少于50个字符。此类评价将显示在：

- 商品卡片上的独立区块中——买家无需进入全部评价页面，即可阅读该评价；

![](../../images/e71aa063d84c8174.png)
在所有变体商品的评价列表中置顶显示。

![](../../images/771f68306fd3d29a.png)

## 置顶评价

进入
[商品 → 评价置顶](https://seller.ozon.ru/app/reviews/reviews-pinned)
模块并找到商品。您可以按名称或货号搜索商品。
在需要置顶评价的商品旁，点击
**选择一条评价**
。页面将跳转至该商品的所有评价列表——仅包含文字的评价会显示，仅含评分不含文字的评价不会显示。

![](../../images/24876a77b00abe7b.webp)

对于同一商品，只能选择一个评价进行置顶。
选择您认为对买家最有帮助的评价。点击评价文本所在行可查看完整内容，然后点击
**置顶**
。

![](../../images/983189247b1bd821.png)

- 进入
[商品 → 买家评价](https://seller.ozon.ru/app/reviews)
部分。
在“评价”列中选择评价并点击。
在“评价置顶”板块中点击
**置顶**
。

![](../../images/5b3f4fd044e1ba2f.webp)

> > 请确认该评价适用于合并到同一商品卡中的所有商品。我们会为该商品的所有变体置顶这条评价。
>

[如何在Ozon Seller应用中置顶评价](/ozon-seller-app/reviews/#置顶评价)

## 替换评价

- 进入
[商品 → 评价置顶](https://seller.ozon.ru/app/reviews/reviews-pinned)
。
找到状态为“评价已置顶”的商品。请使用状态筛选器进行搜索。
点击已置顶的评价。
从列表中选择其他评价：点击评价文本所在行，查看详情后点击
**替换为此**
。

![](../../images/27303547c9521c07.png)

- 进入
[商品 → 买家评价](https://seller.ozon.ru/app/reviews)
部分。
选择已置顶评价的商品。可通过商品名称或商品货号进行搜索。
在“评价置顶”板块中点击
**替换为此评价**
。

![](../../images/02fdda2c9fcf6a38.webp)

之后，我们会在该商品及其所有变体上显示新的评价。

## 取消置顶评价

- 进入
[商品 → 评价置顶](https://seller.ozon.ru/app/reviews/reviews-pinned)
部分。
点击状态为“评价已置顶”的商品。
点击表格中的第一条评价，或点击商品名称下方的模块——我们会显示已置顶的评价。
点击
**取消置顶**
。

![](../../images/3ffb02eb78fd65cd.png)

- 进入
[商品 → 买家评价](https://seller.ozon.ru/app/reviews)
部分。
找到商品并打开评价。已置顶的评价会在其状态旁标有
![](../../images/c97b182c510fa884.png)
图标。
在“评价置顶”板块点击
**取消置顶**
。

![](../../images/6721e5b57ee34d81.webp)

之后，我们将不再把该评价显示在列表首位，也不再将其作为独立模块展示在该商品及其变体的商品卡中。

### 已置顶评价状态

| 服务状态 | 描述 |
| --- | --- |
| 评价已置顶 | 评价已置顶在商品卡片上。 |
| 置顶至（日期） | 评价已置顶在商品卡片上，有效期至订阅期结束。 |
| 没有已置顶的评价 | 商品卡片上没有已置顶的评价。 |
| 评价已取消置顶 | 您已取消置顶该评价。 |
| 置顶错误 | 买家已修改或删除评价。请选择其他评价，或查看修改后的评价并进行置顶。 |

> > 若您将商品归档，状态将变为“置顶错误”。
>

### 下载分析

- 进入
[商品 → 评价置顶](https://seller.ozon.ru/app/reviews/reviews-pinned)
部分。
点击
**附加信息 → 以Excel格式下载分析**
。

![](../../images/905a4a3dde207fec.webp)

报告中会显示整个服务使用期间的数据：

- 服务提供日期；

- SKU；

- 2026年3月31日之前在未订阅状态下进行置顶所产生的费用（单位：卢布）。
