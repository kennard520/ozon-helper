“快速收集评价”手动广告活动是所有可用广告活动中最灵活的一种——您可以自行选择具体商品，设置目标评价数量和广告活动周期。广告活动期间获得的每条评价适用固定出价。

可以同时创建多个手动广告活动。

> > 如果您的余额变为负数，我们可能会暂停收集评价活动，并关闭移动应用中收集评价功能的访问权限。
>

## 启动“快速收集评价”手动广告活动

您可以在工具页面启动手动广告活动：

- 在
**[商品 → 快速收集评价](https://seller.ozon.ru/app/reviews/promotions)**
部分，点击
**创建广告活动**
。

- 为广告活动命名。

- 填写开始日期和结束日期。如果未填写结束日期，广告活动将一直运行，直到收集完所有评价。

- 点击
**添加商品**
。在打开的窗口中，您可以：

- 按名称或SKU搜索商品；

- 按类目、品牌、价格和评价数量筛选商品；

- 以列表形式添加——开启
**列表模式**
，一次性输入多个商品货号或ID。可以从
**[商品 → 商品列表](https://seller.ozon.ru/app/products?filter=all)**
部分的商品报告中复制列表。之后点击
**添加商品**
。我们会为商品设置获取评价的固定出价。

- 在“预算预测”字段中，我们会显示您将用于收集评价的金额。

- 点击
**启用**
。

## 更改“快速收集评价”手动广告活动的设置

您可以随时管理手动广告活动。

### 更改商品列表

在
**[商品 → 快速收集评价](https://seller.ozon.ru/app/reviews/promotions)**
页面打开所需广告活动。

如需：

- 删除商品——选择所需商品，然后点击
**删除**
。在打开的窗口中确认操作；

- 添加商品——点击
**添加商品**
。可以按名称、商品货号搜索商品，也可以使用筛选器。

### 更改评价数量

| **更改广告活动中所有商品的评价数量** | **更改特定商品的评价数量** |
| --- | --- |
| 1. 在
**[商品 → 快速收集评价](https://seller.ozon.ru/app/reviews/promotions)**
页面打开所需广告活动。
2. 点击
**更多 → 设置评价数量**
。
3. 在
**收集评价数量**
列中填写需要收集的评价数量。到达这个数量时，收集将停止。可填写的数量不得少于10条。
4. 点击
**应用**
。 | 1.  在
**[商品 → 快速收集评价](https://seller.ozon.ru/app/reviews/promotions)**
页面打开所需广告活动。
2. 勾选所需商品，然后点击
**设置评价数量**
。
3. 在打开的商品窗口中，填写您想收集的评价数量。到达这个数量时，收集将停止。可填写的数量不得少于10条。
4. 点击
**应用**
。 |

### 更改广告活动日期

1.  在
**[商品 → 快速收集评价](https://seller.ozon.ru/app/reviews/promotions)**
页面打开所需广告活动。

2. 在“活动周期”模块中点击
![Screenshot 2026-05-19 193810](../../images/39ac21de17abd2f0.png)
 并填写其他日期。

## 关闭“快速收集评价”手动广告活动

1.  转到
**[商品 → 快速收集评价](https://seller.ozon.ru/app/reviews/promotions)**
页面。

2. 通过以下任一方式关闭广告活动：

- 在广告活动列表中找到所需的广告活动，点击
![Снимок экрана 2026-10-05 121251](../../images/1281872cd3108a75.png)
 并选择
**停止收集评价**
；

- 在广告活动页面点击
**附加信息 → 停止广告活动**
。

之后，我们将停止激励买家为您的商品留下评价。如果订单是在促销活动期间创建的，并且该订单的评价在买家收到商品后的5天内出现，将按促销活动资费扣款。此类扣款在广告活动关闭后仍可能继续发生，这会考虑配送时间以及5天的评价期限。

**示例**

买家在8月17日创建了订单。您在8月18日关闭了广告活动。如果买家在8月20日收到商品，并在8月24日留下评价，将按促销活动资费扣款：买家收到商品后尚未超过5天，并且商品仍参与广告活动。
