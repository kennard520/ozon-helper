用户可以在商品卡上留下有关商品及其规格的问题。为提高潜在买家的忠诚度并促进他们做出购买决定，您自己可以通过Ozon
 Seller个人中心回复用户问题。回复将以您公司的名义公布。

与
[客服对话框](/promotion/feedback/customers-chat/)
不同，这些问题和回复是公开的，并显示在商品卡上。

![](../images/d8b21f7cd2ca5f87.png)

> > 如果我们发现相同的回答，那么我们可能会暂时限制您的回复功能。请尽量对每个问题单独回答，不要复制文本。买家对模版式的回答很反感，这可能会破坏买家对您和平台的整体印象。
>

## 监控问题

打开
[评价 → 问题和回答](https://seller.ozon.ru/app/reviews/questions)
板块来查看：

- **所有的问题**
：根据日期排列，从新到旧。

- **新的**
：您还没有查看的问题。

- **已查看的**
：没有回答的问题。

- **已处理的**
：其回答已在商品卡片上公布的问题。

![](../images/201049a4cc3bdc4b.png)

我们建议您定期检查问题——快速且详细的回答可以帮助买家做出购买决定。

打开
**菜单 → 评价和问题 → 关于商品的问题**
板块。找到所需的问题：

- 通过名称、货号或者Ozon SKU
 ID来搜索；

- 通过筛选器——可以单独查看：

您还没有查看的新问题；
已查看但未回答的问题；
其回答已在商品卡片上公布的问题。

![](../images/378cb39f636e33db.png)
请在
**菜单 → 通知设置**
板块中开启通知功能，这样您将不会错过新问题。

## 回答问题

回答应具有信息性，仅针对该商品，且不包含其他商品或贵公司网站的链接。审核人员将拒绝发布带有污言秽语、意在辩论或侮辱其他用户的回答。

[问题和回答发布规则详情](https://docs.ozon.ru/legal/terms-of-use/site/content-policy/)

打开
[评价 → 问题和回答](https://seller.ozon.ru/app/reviews/questions)
板块。您可以查看来自用户的新问题或根据货号或名称找到有关特定商品的所有问题。

![](../images/e69c2a72710ea338.png)

- 单击您要回复的问题。您会看到该问题的基本信息以及其他用户对该问题作出的回答。

- 如您此前还未《客服沟通编辑规则》，请先接受后再进行操作。

问题的回复必须内容明确，只针对具体商品，不包含其他商品或您自营网站的链接。管理员还将屏蔽包含淫秽语言以及意图挑拨或侮辱其他用户的回复。您可以更详细地了解
[发布问题和回复的规则](https://docs.ozon.ru/common/pravila-prodayoi-i-rekvizity/pravila-publikatsii-otzyvov/pravila-publikatsii-voprosov-otvetov)
 。
请在
**问题回复**
 字段写下您的回答，然后单击
**发送回复**
 。您的回复将在通过审核后进行发布。此过程通常不超过一周。
用户将根据设置通过推送通知或电子邮件的形式收到您的回复。

打开
**菜单 → 评价和问题 → 关于商品的问题**
板块。

- 找到所需的问题并点击它。

- 输入回答并点击
![](../images/d1e30db80ba35e03.png)
。

![](../images/8cae31f6e4c66797.png)

信息可以删除——请点击信息下方的
![](../images/8be59605f4064c0f.png)
并确认操作。

通常审核时间不会超过7天。如果已经超过了7天，请与
[客服](https://seller.ozon.ru/app/messenger?channel=SCRM)
取得联系。选择
**内容 / 商品卡片管理 → 用户评价和问题**
主题。在申请中请输入商品的Ozon SKU
 ID和商品问题回答日期。如果有回答截图，请一并附上。

## 回答审核状态

我们将在个人中心和应用中的回答旁边显示其状态。请注意，在该板块中系统不仅仅显示关于该商品的来自您的回答，还将显示官方代表和其他买家的回答。无法对其他用户和品牌代表进行回答限制。

## 无法回答问题

在下列情况下您将无法回答问题：

- 您已将商品下架或归档，因此商品不在网站上。请在
[商品 → 商品列表](https://seller.ozon.ru/app/products?filter=all)
板块中查看商品的可用性。

- 您处于黑名单中。如果审核人员多次因违反
[编辑方针](/policies/communication/)
和
[问题和回答公布规则](https://docs.ozon.ru/legal/terms-of-use/site/content-policy/)
对您提出警告，那么您可能会进入黑名单。
