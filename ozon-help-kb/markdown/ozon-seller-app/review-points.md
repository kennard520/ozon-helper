## 启动自动活动

- 在
**菜单 → 快速收集评价**
模块中打开自动促销活动。

- 查看促销活动预测是否符合您的预期：

预计转化率——商品被加入购物车的频率；
参与促销活动的商品数量；
促销活动预计花费；
可获得的评价数量。
点击
**启动活动**
。

## 启动“快速收集评价”促销活动

打开
**菜单 → 快速收集评价**
模块。
点击
**添加活动**
。
设置促销活动名称。
指定促销活动开始和结束日期。

如果不指定结束日期，促销活动将一直进行，直到收集到所有评价。
点击
**添加商品**
。
勾选将参加促销活动的商品。可以按以下条件筛选：

类目，
品牌，
价格，
评价数量。
点击
**继续**
。

默认情况下，我们会为每个商品设置收集10条评价。

您也可以自行指定需要收集的评价数量。
点击
**启动活动**
。

## 更改评价收集设置

只能更改“快速收集评价”促销活动的设置。

### 向促销活动中添加商品

在
**菜单**
 →
**快速收集评价**
模块中打开活动。

- 点击显示商品数量的区块，然后点击
**添加商品**
。

- 勾选要添加到促销活动中的商品。

- 点击
**保存**
。

### 从促销活动中删除商品

- 在
**菜单 → 快速收集评价**
模块中打开促销活动。

- 点击显示商品数量的区块，然后点击相应商品旁边的
![](../images/ad46c08990d39270.png)
。

- 点击
![](../images/473638857ccf20ee.png)
并确认删除。

### 更改评价数量

- 在
**菜单 → 快速收集评价**
模块中打开促销活动。

- 点击
**设置评价数量**
。

- 为商品指定需要收集的评价数量。

- 点击
**保存**
。

如需为具体商品设置出价，请点击显示商品数量的区块，并在相应商品处按不同评价类型指定以卢布计的出价金额。

### 更改促销活动日期

- 在
**菜单 → 快速收集评价**
模块中打开促销活动。

- 点击促销活动名称旁边的
![](../images/ad46c08990d39270.png)
，编辑促销活动。

- 指定新的日期并点击
**保存**
。

## 关闭快速收集评价

- 在
**菜单 → 快速收集评价**
模块中打开促销活动。

- 点击
**停止活动**
并确认操作。

## 启动自动促销活动

- 在
**菜单 → 积分评价**
 中打开自动促销活动。

- 查看促销活动的预测是否令您满意：

预计转化率 —
 商品被加入购物车的频率；
参与活动的商品数量；
活动的预计花费；
可以获得的评价数量。
点击
**启动活动**
。

## 启动“用积分吸引买家”促销活动

打开
**菜单 → 积分评价**
 。
点击
**添加到促销活动**
。
为促销活动起一个名称。
设置促销活动的开始和结束日期。

如果未设置结束日期，促销活动将持续至所有评价收集完成。
点击
**添加商品**
。
勾选要参与促销活动的商品。可以通过以下条件筛选：

类目；
品牌；
价格；
评价数量。
点击
**继续**
。

默认情况下，我们为每个商品设置 10 条需要收集的评价，以及每条评价的
[推荐出价](/promotion/feedback/customer-reviews/points-for-reviews/start-reviews-for-points/#最低与推荐积分)
。

您可以
[自定义评价数量和积分](#修改评价数量和积分)
。
点击
**启动活动**
。

## 修改评价收集设置

仅“用积分吸引买家”促销活动的设置可进行修改。

### 添加商品到活动

在
**菜单 → 积分评价**
 中打开目标活动。

- 点击商品数量模块，然后点击
**添加商品**
。

- 勾选需要添加到活动的商品。

- 点击
**保存**
。

### 从活动中删除商品

- 在
**菜单 → 积分评价**
 中打开目标活动。

- 点击商品数量模块，然后点击目标商品旁的
![](../images/ad46c08990d39270.png)
 图标。

- 点击
![](../images/473638857ccf20ee.png)
 并确认删除。

### 修改评价数量和积分

- 在
**菜单 → 积分评价**
 中打开目标活动。

- 点击
**设置出价和数量**
。

- 对于每个价格区段的商品，设置：

需要的评价数量；
不同类型评价对应的积分数量。
点击
**保存**
。
要为具体商品设置积分，点击商品数量模块，在目标商品旁设置不同类型评价的积分。

### 修改活动日期

在
**菜单 → 积分评价**
 中打开目标活动。

- 点击活动名称旁的
![](../images/ad46c08990d39270.png)
 图标进入编辑模式。

- 设置新日期并点击
**保存**
。

## 停止积分评价活动

- 在
**菜单 → 积分评价**
 中打开目标活动。

- 点击
**停止活动**
 并确认操作。
