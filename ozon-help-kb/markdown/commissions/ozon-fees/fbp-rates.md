[返回FBP部分](/fulfillment/fbp/)

在FBP模式下，Ozon的佣金相较于自行仓库发货模式，降低1%。

## CEL, GUOO, RETS, Ural, Xingyuan

您可以选择以下方式：

- 自行将商品运送至仓库。

- 通过接收点配送商品。该服务适用于以下仓库：GUOO、Ural。

[了解更多揽收点地址的信息](https://global-help.ozon.com/zh/fulfillment/fbp/warehouse?region=CHN)

- 使用从您指定地址取货的配送服务。


[了解 GUOO 和 Ural 仓库的服务详情](/fulfillment/fbp/supplies/pick-up/)

**验收**

免费。 包括接收、检查和清点商品，并将其放置在货架上。 请确保商品上已贴上条形码条形码。如果没有条形码，则需要额外支付标签服务费用。

**发运准备**

免费。 包括：

- 订单备货与检查，

- 打印并贴上运输标签，

- 将货件移交给物流公司。

如果您需要商品的包装服务，需另行支付费用。

包括商品的安全存储和库存盘点。

| 存储期限 | 费用 |
| --- | --- |
| 1–90天 | 免费 |
| 91–120天 | 每立方米每天4元 |
| 121–180天 | 每立方米每天6元 |
| 超过181天 | 每立方米每天8元 |

- 我们为每个商品单位单独计算存储天数，从验收日期开始计算。

- 商品根据FIFO原则发运——首先到达仓库的商品首先发运。

- 合作伙伴可以在促销活动期间延长免费存储期限。

- 结算直接与合作伙伴仓库进行。

免费。 包括商品的备货、检查和准备退货给卖家。运输费用由卖家承担。

额外收费的服务包括：

- 商品标签 —— 打印带条形码的标签。 如果商品在入库时未贴条形码或需要更换条形码，则需要该服务。

> > 货盒的标签免费。
>

- 运输包装。 如果商品在入库时未包装或包装不符合Ozon标准，仓库可以自行为商品进行包装。

服务费用请向所选仓库查询。

## DEX仓库

**

标准操作费
**

该费用适用于从仓库发运的货件：

- 计费单位：货件；

- 价格：3美元。

服务内容包括：

- 验收：

卸货、清点、数量与质量检查；
扫描序列号和 IMEI；
商品上架存放。

请确保商品上已贴有与 Ozon 系统中一致的条形码。
仓储——自验收之日起 30 天内免费，之后需
[另行](/commissions/ozon-fees/fbp-rates/?country=CN#tab/1/仓储)
付费。
发运准备：

订单备货与核对；
使用包装材料对商品进行运输包装；
打印并粘贴物流标签；
若订单在仓库发运前被取消，将商品退回货架；
将货件移交给物流公司。
仓储

为商品提供安全存储及定期盘点。

| 存储期限 | 费用

 USD/立方米/天 |
| --- | --- |
| 1–30 天 | 包含在标准操作费中 |
| 31–60 天 | 4 |
| 61–90 天 | 8 |
| 超过 91 天 | 16 |

存储天数按每一批商品自验收之日起单独计算。 商品按照 FIFO 原则发运——先验收的商品优先发运。
