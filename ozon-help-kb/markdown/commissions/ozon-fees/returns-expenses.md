本文适用于发往俄罗斯联邦的订单。

| 退货类型 | 描述 |
| --- | --- |
| 取消 | • 订单在配送给买家前被取消。

 • 买家在订单保管期届满前未取货。

 • 买家在收到前拒收订单。 |
| 未认购 | 买家在取货点检查商品后，部分或全部拒收订单。已认购商品状态变更为“已签收”，未认购商品状态变更为“已取消”。 |
| 客户退货 | 买家提交已收货商品的退货申请，我们审核通过后，在取货点接收商品并向买家退款。 |

商品处理方式取决于Ozon的规则及您在个人中心的设置。

费用取决于退货发往何处：

- [通过WHD仓库发送退货](#通过whd仓库发送退货)
——使用Ozon配送服务；

- [退货发送到Ozon合作伙伴仓库](#FBP与realFBS取消、未认购及客户退货的其他服务费用)
——若指定了物流合作伙伴或退货服务商；

- [由Ozon销毁退货](#通过-whd-仓库进行商品销毁)
——若指定了Ozon销毁。

## 通过WHD仓库发送退货

对于取消、未认购、客户退货，Ozon组织退货商品的接收并将其发往仓库，以便在平台上进行转售。

若仓库发出的商品发生重复取消、未取货或客户退货，我们将安排将该商品发往仓库。

将商品发往仓库需同时满足以下所有条件：

- 您的
[发货至仓库](https://seller.ozon.ru/app/returns/rfbs/settings?fromRfbs=true)
设置可用且未关闭。

- 客户
[未对商品质量提出索赔](/fulfillment/rfbs/refunds/returns-3pl/?country=CN#质量合格商品的退货条件)
 ，且商品符合合格商品标准。若仓库收货时发现轻微瑕疵，例如包装损坏，该商品将进行减价处理。

[关于减价商品的更多信息](/products/price-reduction/)

- 商品可在仓库接收，且不属于
[禁售商品清单](/policies/product-rules-and-documents/product-rules/special-categories/)
。

- 按订单当日
[换算汇率](/accounting/conversion-rate/)
 计算，个人中心中的商品价格超过500卢布。

当取消或未取货商品送达仓库进行转售时，我们将按照已签收订单的标准收取
[Ozon合作配送费用](/commissions/ozon-fees/partner-delivery-rates/)
。

转售时将适用22%的增值税，Ozon将代您向俄罗斯联邦预算缴纳该税款。同时，面向买家的最终价格保持不变，而卖家实收价格将扣除相应税费的金额。

商品退回仓库时，Ozon提供一系列服务，每项服务单独计费。

| 服务 | 包含内容 |
| --- | --- |
| 逆向物流 | 接收取消、未认购、客户退货并将其发往仓库。 |
| 取消及未认购商品处理/Ozon退货处理 | 仓库收货及商品状态检查。 |
| 存储 | 仓库存放及存储，最长不超过120天。部分存储期限已包含在“物流”服务费率中。超出后——付费存储。 |
| 物流 | 再次下单时的拣货、包装、仓库分拣及运送至分拣中心。 |
| 非标准商品处理 | 搬运非标准商品时，在仓库使用特殊设备、多名员工、非标准托盘和运输固定装置。 |
| 配送至取货点 | 订单从分拣中心配送至客户取货点 —— 取货点、自助提货柜、邮局及其他地点。 |
| Ozon合作伙伴处理 | 合作伙伴在取货点接收重复未取货或退货。 |
| 销毁 | 商品销毁条件如下：

• 商品入库已满120天；

• 商品严重损坏或变质。 |

### 逆向物流

**自2026年5月6日起**

我们将收取取消、未认购或客户退货的接收、发往仓库及必要时进行商品状态检查的服务费用。

“取消及未认购商品处理”和“Ozon退货处理”服务费用已包含在逆向物流费用中。

逆向物流费率等同于服务提供时生效的“物流”服务费率。

服务提供时刻：退货入库仓库。

汇率换算：按俄罗斯联邦中央银行在服务提供时的汇率计算。

### 仓库存储

**自2026年5月6日起**

商品最长存放期限为120天。

每件商品在一定天数内不收取额外费用——相关费用已包含在“物流”服务费率中。

部分类目适用特殊费率。对于此类商品，我们在特定时期内延长免收额外费用的天数。

[免收费用存储期限（XLSX）](https://cdn.ozone.ru/s3/ozon-disk-api/Partner_Delivery/terms_of_placement_01_03_2026_1773823956.xlsx)

每日按每升商品收取费用，含增值税：

- 普通商品——每升每日2.50卢布；

- 超大货物——每升每日0.10卢布；

- 易燃商品——每升每日0.60卢布；

- 轮胎仓库商品——每升每日0.14卢布。

服务提供时刻：商品入库当日结束时。

汇率换算：按俄罗斯联邦中央银行在服务提供时的汇率计算。

| 商品类目 | 特征 |
| --- | --- |
| 超大货物 | • 长度：45–220厘米，

 • 宽度：45–220厘米，

 • 高度：32–80厘米，

 • 重量：最高120公斤 |
| 易燃商品 | 除
[仓库销售限制](/policies/product-rules-and-documents/product-rules/special-categories/?country=CN)
范围内的危险类目商品 |
| 普通商品 | 不属于上述类目的商品 |

若商品自收货之日起120天内未能转售，将发往
[销毁](#通过-whd-仓库进行商品销毁)
。

**存储期限计算**

免费存放期限自商品入库之日起计算——根据入库时的类目及条件确定。费率变更时，已存储商品的期限保持不变。

### 转售物流

**自2026年5月6日起**

物流费用包括拣货、包装、仓库内商品分拣、包装材料成本，以及从发运集群到目的集群的配送。

运输费率取决于体积及具体配送方向。

[下载费率表（XLSX）](https://cdn.ozone.ru/s3/ozon-disk-api/Partner_Delivery/Logistics_06_04_2026_1774594690.xlsx)

若因技术原因无法确定发运集群或目的集群，我们将根据商品体积按通用费率收费。

[关于集群的详细信息](/prices/regional-price/)

服务提供时刻：商品送达分拣中心。

汇率换算：按俄罗斯联邦中央银行在订单创建时的汇率计算。

[计算仓库商品体积](/fulfillment/fb-global/volume/)

### 非标准商品处理

> > 自2026年6月1日起生效。
>

该服务适用于搬运时需要使用特殊设备、多名员工、非标准托盘和运输固定装置的商品。这些商品包括：

- 重量超过25公斤的商品，

- 表格中列出的类目商品：

[下载非标准商品表格](https://cdn.ozone.ru/s3/ozon-disk-api/global-education/zh/commissions/ozon-fees/returns-expenses/non_standard_items_CHN_1779443737.xlsx)

服务费用为卖家在个人中心设置的商品价格的3%，但不超过280卢布，按订单日期的
[换算汇率](/accounting/receiving-payments/conversion-rate/)
计算。

服务提供时间：商品配送至分拣中心。

### 配送至取货点

**自2026年5月6日起**

订单从目的集群的分拣中心配送至客户取货点：订单取货点、自助提货柜、邮局、买家地址或其他地点。

若服务由以下方提供：

- 执行者合作伙伴——我们将收取“合作伙伴配送至取货点”服务费用，该费用取决于合作伙伴的最终报酬，但不超过25卢布 (不含增值税)。 Ozon为吸引合作伙伴而支付的报酬已包含在销售报酬中。

- Ozon——我们将收取“Ozon配送至取货点”服务费用。服务费用为25卢布。适用于Ozon未能吸引执行者合作伙伴进行配送的情况。例如，航空配送、跨境配送或第三方承运商未覆盖的偏远地区配送。

汇率换算按俄罗斯联邦中央银行在订单创建时的汇率计算。

若发生取消、未认购或客户退货，我们将收取该服务费用。

### Ozon合作伙伴在取货点的处理服务

**自2026年5月6日起**

向取货点支付的费用，用于合作伙伴在取货点接收和处理重复未取货或客户退货。

费率：每件商品15卢布 (不含增值税)。

服务提供时刻：在取货点接收未认购或客户退货。

汇率换算：按俄罗斯联邦中央银行在服务提供时的汇率计算。

### 通过 WHD 仓库进行商品销毁

**自2026年5月6日起**

服务费用根据销毁原因按商品重量单独计算并收取。每公斤单价乘以商品重量 （精确至克），不进行四舍五入。

对于重量不足1公斤的商品，按1公斤费率计算。

销毁费用不得超过该服务的最高费用。

服务费率：

| 原因 | 每公斤费率，含增值税（卢布） | 服务最高费用，含增值税（卢布） |
| --- | --- | --- |
| 退货及取消自动销毁 | 25 | 125 |
| 库存自动销毁 | 25 | 125 |
| 您订购的销毁服务 | 25 | 125 |
| 因包装而损坏 | 75 | 375 |
| 已损坏，曾位于买家处 | 25 | 125 |
| 禁售商品 | 75 | 375 |
| 保质期已过 | 75 | 375 |
| 因包装缘故而溢出/洒出 | 75 | 375 |

服务提供时刻：商品发往销毁时。

汇率换算：按俄罗斯联邦中央银行在服务提供时的汇率计算.

## 未认购及客户退货的其他服务费用

如果退货发往仓库不适用或您已禁用该选项，我们将执行：

- 商品销毁；

- 通过物流合作伙伴或退货服务商将退货转交至合作伙伴仓库。

### 销毁

适用于在通过WHD仓库配送之前即被送去销毁的商品；其余情况请参见WHD模块。

发生取消、未认购商品和客户退货时，Ozon不会向您收取逆向货件的处理费用，包括销毁费用。

商品的权利和义务转移给接收商品的合作伙伴，此后有关商品的决定由其自行作出，Ozon不参与。

### 转交至合作伙伴仓库

商品的权利和义务转移给接收商品的合作伙伴，此后有关商品的决定由其自行作出，Ozon不参与。

[关于仓库设置的更多信息](/fulfillment/rfbs/logistic-settings/warehouse/)

Ozon在取货点处理取消、未认购商品和退货的服务不额外收费。

[关于处理取消与退货的更多信息](/fulfillment/fbp-rfbs-returns-cancellations/)
