## 为员工创建账号

- 在公司主管或具有“管理员”角色的员工的个人中心中，点击右上角的

![](../images/449820690f8f47d9.png)

然后进入页面
[设置 → 员工](https://seller.ozon.ru/app/settings/employees)
。

- 请点击
**邀请员工**
。

![](../images/ec13a5477a798090.png)

- 请输入员工的电子邮箱、角色，并点击
**邀请**
。

> > 请不要使用以 *
> .co 或 *
> .su 结尾的电子邮件地址
> -系统中将无法注册。
>

- 系统将向指定的邮箱发送一封包含账户激活链接的邮件。

> > 激活链接有效期为24小时。
>

当员工确认注册后，在其角色对应的
**状态**
列中会显示“处于活动状态”。

## 邀请函

### 邀请状态

在签页
**员工名单**
:

- “激活”：该员工已获得个人中心的访问权限；

- “未激活”：该员工尚未点击邮件邀请中的链接。

在签页
**邀请函历史记录**
:

- “已发送”：邀请已发送给该员工；

- “接受”：该员工已点击邮件中的链接，并获得个人中心访问权限；

- “已撤回”：邀请在员工接收前已被撤销。

### 邀请历史

要查看邀请历史记录，请转到
[设置 → 员工 → 邀请函历史记录](https://seller.ozon.ru/app/settings/employees)
。

![](../images/fa158cc5c428da59.png)

您可以:

- 取消尚未接受的邀请：点击
![](../images/406b6587f0fb8694.png)
 →
**撤回邀请**

并确定操作；

![](../images/74f03895206456c4.png)

- 通过电子邮件地址查找邀请：在字段中输入地址
**按姓名或电子邮箱搜索**
；

- 按状态筛选：请点击
**状态**
并标记您所需要的;

- 按角色过滤：点击
**角色**
并标记需要的；

- [发送邀请](#为员工创建账号)
。

## 删除员工账户

> > 具有“主管”或“管理员”角色的用户可删除员工账户。
> 如果您要删除具有管理权限的员工，请确保其先行移交权限。
> [了解更多关于权限移交](#将管理权限转移给其他员工)
>

- 请转到页面
[设置 → 员工](https://seller.ozon.ru/app/settings/employees)
。

- 在员工行中，单击
![](../images/406b6587f0fb8694.png)
 →
**删除用户 → 确认**
。
![](../images/caa2bf1a8cf44447.png)

## 更改员工角色

- 请转至
[设置 → 员工](https://seller.ozon.ru/app/settings/employees)
并找到所需员工。

- 请在员工行点击
![](../images/406b6587f0fb8694.png)
 →
**更改角色**
并选择新的.

![](../images/ab2b66002dbb347c.png)

## 将管理权限转移给其他员工

请进入
[设置 → 员工](https://seller.ozon.ru/app/settings/employees)
。
在员工对应的行中，点击
![](../images/406b6587f0fb8694.png)
 →
**更改角色 → 经理**
。
只有当前主管可以将经理角色分配给新员工。

## 恢复权限

如果需要恢复主管的个人中心访问权限，

请进入
[设置 → 账户](https://seller.ozon.ru/app/settings/name-password)
并联系
[帮助中心](https://seller.ozon.ru/app/messenger?channel=SCRM)
。

提交恢复访问请求：

请指出：

新的电子邮件地址；
贵公司的法律组织形式。
附加文件：

护照和/或授权书的复印件或照片；
第2-3页的护照照片。
我们将查验信息，如果一切正常，我们将恢复访问您的个人中心。

如果需要恢复除主管以外的其他角色的访问权限，可以
[创建新账户](#为员工创建账号)
（使用不同的邮箱），然后删除旧账户。

## "快递员"、"备货人员"和"备货人员-快递员"角色可用数据

"快递员"、"备货人员"和"备货人员-快递员"角色适用于 realFBS
 模式的卖家。

这些角色可以分配给任意数量的员工。如需分配，请创建员工账户并指定所需角色。

[了解更多关于创建账户的信息](#为员工创建账号)

角色不能与其他角色组合使用 ——
 需要先撤销旧角色，然后再指定新角色。

"快递员"、"备货人员"和"备货人员-快递员"只能通过 Ozon Seller
 应用程序访问个人中心。他们可以查看以下部分：

**首页**
——仅显示订单和退货的数量和状态，其他信息隐藏；

- **订单**
——仅显示部分数据；

- **退货**
——仅显示部分数据；

- **帮助**
；

- **菜单**
。
