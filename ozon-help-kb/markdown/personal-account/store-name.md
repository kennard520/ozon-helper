## 名称

您可以在 Ozon 卖家账户注册时填写店铺名称，或在注册后进入
[商品 → 橱窗 → 商店设计](https://seller.ozon.ru/app/showcase/constructor/seller/)
页面中进行设置。

拥有“主管”和“管理员”权限的员工可以更改商店名称。

### 商店名称要求

名称长度应在2至140个字符之间。名称可使用西里尔字母或拉丁字母，不区分大小写。

名称中不能包含：

- 污言秽语；

- 表情和特殊符号；

- 空格和数字；

- 错别字；

- 店铺联系方式、网站链接和电话号码；

- 在未经认证的情况下使用“最佳”、“第一”和“最”等字样；

- 商品种类列举；

- 他人商标名称；

- “Ozon”或“Озон”字样。

系统将自动把名称前后的空格去掉。

### 更改商店名称

只有在签订
[合同](/launch/steps/step-2)
之后才能更改商店名称。

- 进入
[商品 → 橱窗 → 商店设计](https://seller.ozon.ru/app/showcase/constructor/seller/)
，切换到
**橱窗数据**
标签页。

- 在
**商店名称**
栏中输入新名称，然后点击
**提交审核**
。

![](../images/66238eda839813ec.webp)
新名称不能与当前名称、正在审核的名称或之前拒绝过的名称一致。

审核人员将在两个工作日内审核您提交的新店铺名称。我们将通过电子邮件通知您审核结果，同时在
**橱窗数据**
标签页中显示审核状态。您还可以在
**更改历史记录**
模块中查看当前申请状态、旧的店铺名称、以往申请的状态及其审核日期。

![](../images/10f56bac5fa1f045.png)

可能的状态包括：

“已确认” —
 名称已通过审核；

- “正在验证中” —
 名称正在验证；

- “自动更改” —
 名称因违规被拒，系统已将其替换为组织的法定名称，或为个体经营者的全名（前提是之前未确认过任何名称）；

- “手动更改” —
 Ozon技术支持人员已修改您的店铺名称；

- “已被拒绝” —
 名称未通过审核；

- “已取消” —
 您提交了多个申请，或使用了之前未通过审核的名称。

如果名称没能通过审核，那么我们将自动将其替换成：

- 公司法定名称；

- 之前确认过的名称。

如果买家在商品卡片上把光标悬浮在商店名称旁边的
![](../images/34ea715319a9c84f.png)
 上，那么他将看到公司的法定名称——根据《消费者权益保护法》规定，Ozon无法隐藏这些信息。

### 更改商店法定名称

如果您商店的法定名称发生了变化，请
[在聊天室中通知我们](https://seller.ozon.ru/app/messenger?group=support&helpCenter=create-issue)
或写信至
[marketplace.crossborder@ozon.ru](mailto:marketplace.crossborder@ozon.ru)
。请在请求中附上以下材料：

- 有关详细信息更改的官方信件。请在信件中指出您需要更改详细信息的Ozon合同编号。信件应由商店主管签名并盖章以作证明。

- 您还需提供组织信息卡的文本格式，以及带有彩色印章和主管签名的原件扫描件。

## 标志

只有具有“主管”或“管理员”角色的员工才能更改店铺标志。

### 标志要求：

- 尺寸为 200 × 200
 像素；

- 文件大小不超过 200
 KB；

- 文件格式为 JPG、PNG 或
 WEBP。

### 更改标志

您可以在
[商品 → 橱窗 → 商店设计](https://seller.ozon.ru/app/showcase/constructor/seller/)
页面中，打开
**橱窗数据**
标签页来修改标志。

要删除旧标志，请在
**标志**
区域点击图片上的
![](../images/a15805186ff20a1c.png)
 图标。

要上传新标志：

- 点击
**选择文件**
 并添加图片。

- 点击
**发送进行审核**
。

![](../images/a86dd70c494d3f3d.png)

更改后，标志将提交审核。审核时间不超过 3 天。审核状态将在
**标志**
区域中显示。可能的审核状态包括：

- “已通过审核” —
 标志已通过审核并发布；

- “审核中” —
 正在审核标志；

- “审核未通过” —
 标志未通过审核，系统会提示需修正内容。

如果标志未通过审核，系统将自动恢复为默认标志。

## 店铺链接与二维码

在
[商品 → 橱窗→ 商店设计](https://seller.ozon.ru/app/showcase/constructor/seller/)
 页面中的
**橱窗数据**
选项卡，会显示您的店铺链接和二维码。您可以将它们分享给买家。

在“店铺链接”部分，您可以选择链接格式：点击
**名称**
或
**Seller ID**
。

![](../images/5c70bd86d28eb9d0.webp)

若您选择了
**名称**
，则可对链接进行编辑。请使用拉丁小写字母、数字和连字符。请勿使用：

- 链接开头或结尾的连字符；

- 链接末尾的连字符与数字组合，例如：-12345；

- 不雅词汇或涉及极端主义的词汇。

只有具有“主管”和“管理员”权限的用户才能提交新链接以供审核。为此，请点击
**发送进行审核**
。可能的状态如下：

- “已通过检查”——链接已通过审核，原链接将失效。

- “审核中”——链接正在接受审核，无法编辑。

- “已拒绝”——链接未通过审核，原因可能包含非法字符、不雅词汇，或该链接已被使用。

- “已更改”——新链接被拒，系统已自动恢复上一个通过审核的链接。

如需复制链接，请在
**店铺链接**
 模块中点击
![](../images/3a9b2681d5974dc0.png)
。

在
**店铺专属二维码**
 模块中，您可以：

- 为二维码添加说明文字——启用
**添加签名**
；

- 以 PDF 格式下载二维码——点击
**以PDF格式下载**
；

- 复制二维码——点击
![](../images/3a9b2681d5974dc0.png)
。

![](../images/0e8bd0befd55cd94.webp)

如果店铺链接发生变化，二维码仍将保持不变——无需重新更新传单或名片上的二维码。
