Performance
 API用于自动化Ozon广告中心的运作。借助于外部API，您可以:

- 收集多个广告渠道的统计数据；

- 将商品添加至广告；

- 优化出价。

开通API需要密钥。若其已存在，但已过期,
[请删除密钥](#更改或删除api密钥)
并创建新的密钥。

## 获取API密钥

- 请转至
[设置 →API密钥](https://seller.ozon.ru/app/settings/api-keys)
部分并选择
**Performance API**
。
若您:

在Ozon
 Performance服务中拥有账户，那么请选择该账户。

![](../images/b50dd3165827fe5d.png)
没有账户，那么请点击
**创建账户**
。如要区分您正在集成的多个应用程序或合作伙伴的访问权限，请创建多个帐户。

![](../images/79fb47eef18e261e.png)
通过Ozon
 Performance账户可以每天最多发送10万份请求。

请在账户列表中选择所需账户并点击
**添加密钥**
。您可以放出多个密钥。

![](../images/b3cb83a85ef5dd67.webp)
