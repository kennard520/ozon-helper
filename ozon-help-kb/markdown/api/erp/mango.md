## ERP介绍

芒果店长是国内最早的SaaS ERP平台之一，创立于2014年,是中国外贸信息化服务领军企业——富通天下旗下品牌。公司已累计服务全球电商卖家超60万家,日处理订单超500万家。
 通过与全球30余家主流跨境电商平台合作,无缝对接500余家物流公司API接口，深度打通电商平台、物流仓储与卖家。

芒果店长致力于成为对新手友好的ERP工具，围绕采集、产品、订单、物流、采购、客服、数据以及库存8大核心功能打造跨境电商垂直领域的智慧商业服务生态, 以“技术+服务”为核心资源优势, 凭借多平台多店铺集约化电商管理解决方案，赋能全球电商卖家高效运营全链路。通过跨境电商交易大数据,
 精准助力卖家规模化发展。

## 支持功能汇总

**芒果店长插件采集**

支持130+网站采集，包括1688、拼多多、速卖通、Ozon等网站采集，使得上品更加快速。

**支持Ozon多sku产品刊登和批量上传**

- Ozon多sku产品刊登；

- Ozon单sku产品刊登；

- 产品批量编辑；

- 定时发布、变体属性、类目翻译；

- 图片翻译、中翻俄以及英翻俄一键翻译、图片在线美化、sku图片位置调整、图片一键白底、水印设置、首图设置;

- Ozon定价工具；

- 本地视频上传；

- Ozon产品证书上传；

- json富文本模板编辑器；

- json尺寸表模板编辑器。

**支持Ozon在线产品管理**

在线产品批量编辑、在线产品管理、产品来源查询、在线产品批量存档、店铺搬家、平台搬家、在线产品批量填写库存、在线产品批量修改价格、在线产品批量更换仓库。

**订单处理**

Ozon线上物流面单批量打印、Ozon集成物流面单批量打印、Ozon非集成物流面单批量打印、订单处理、虚拟发货、追加包裹、拆分包裹、合并订单、自动化确认订单并生成包裹、可以设置黑名单、订单来源查询。

**Ozon自动调价**

汇率波动较大时，可以自定义设置基准汇率，自动调整产品价格。

**Ozon售后问题回复及邮件营销**

- 售后消息、客服消息查看及回复；

- 支持给下过单的买家发送营销邮件，支持催下单、催签收等。

**对接物流商**

对接500+物流商，Ozon线上物流、Ozon集成物流、Ozon非集成物流、物流轨迹跟踪。

**采购**

1688及拼多多采购订单无缝衔接、智能化采购建议、标准化采购流程。

**Ozon数据**

- 订单、利润、客户等多维度数据精细化统计、订单利润预估;

- 支持Ozon销售报告下载。

**Ozon广告活动和促销活动**

商品推广促销活动管理

**本地仓库**

本地仓储管理、出入库登记规范化。

**Ozon选品对接**

支持OZON销量插件、行业数据、热销产品数据、热销关键词数据、跟卖产品检测等

**子账号设置**

主账号可分配权限给子账号，方便管理。
