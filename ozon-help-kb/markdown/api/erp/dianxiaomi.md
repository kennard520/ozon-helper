## ERP介绍

深圳美云集网络科技有限责任公司成立于2014年，是一家全球领先的电商IT服务公司，专注于为全球电商卖家提供SaaS系统服务，让“买全球、卖全球”变得更简单。

店小秘聚集国内强大的IT研发团队，核心成员来自百度、腾讯、美团等知名企业，具备15年+软件研发经验，深耕跨境电商行业十余年，专注解决全球电商卖家痛点，

每年超千次迭代优化，致力让全球生意更高效。

截止目前，店小秘服务的全球用户已超过150万，并与全球50多家顶级电商平台、1600多家优质物流商及80多家海外仓实现深度合作，年处理的订单交易金额超3500亿人民币。

## 支持功能汇总

### 支持Ozon多SKU产品刊登

- Ozon单/多SKU产品刊登;

- 产品采集并发布至Ozon;

- 设置认领规则;

- 产品搬家并发布至Ozon;

- GPT一键发布至Ozon;

- 设置店铺币种、一键同步仓库;

- 产品发布（定时发布、价格检测、违禁词检测）;

- 分类及属性翻译中文展示;

- 批量应用图片、图片编辑（改图片尺寸大小、图片一键翻译、图片一键白底、图片加水印、小秘美图、在线美图）;

- 支持编辑并上传JSON尺码表及JSON富内容;

- 批量编辑（标题、属性、价格、库存、重量、尺寸等）;

- 批量操作（批量发布、批量定时发布）;

- 在线产品管理（复制产品、合并产品统一展示、产品划分状态展示、产品发布失败描述展示、产品可见性）;

- 产品内容质量分同步展示;

- 模板管理（Ozon产品模板、Ozon尺码模板、Ozon定价模板、Ozon富内容模板）;

- 支持管理、同步促销活动及管理活动产品。

### 支持处理Ozon消息

- 消息管理（买家消息、Ozon客服、Ozon通知）;

- 支持支持上传附件，消息模板应用;

- 会话式消息展示、一键翻译消息内容;

- 查看买家订单信息。

### Ozon订单处理

- 自动同步Ozon订单;

- 支持授权Ozon线上 &
 近千家线下物流商;

- 支持按规则自动审核订单;

- 支持按规则自动追加赠品;

- 支持预估各渠道运费，按规则自动分配最便宜的物流渠道;

- 支持永久报关，相同产品报关仅需填写一次;

- 支持多店铺批量打印面单，一次打印1000单;

- 支持加打拣货单/配货单;

- 支持扫描分拣自动打印面单;

- 支持打印发票;

- 支持扫描称重发货，提高拣货效率和准确率;

- 支持多维度搜索查找/导出订单;

- 支持添加自定义客服/拣货备注/标记;

- 支持添加/共享云黑名单，避免信誉差买家拒收;

- 支持查看预估订单利润，避免亏损;

- 支持添加采购来源，方便采购;

- 支持通过图片到淘宝/1688找低价货源;

- 支持自动追踪包裹物流信息;

- 支持查看包裹具体操作记录。

### Ozon采购仓库

- 支持添加多个自营仓库;

- 支持授权第三方海外仓，同步库存;

- 支持添加单个/组合/多属性/加工商品;

- 支持从其他ERP导入商品;

- 支持同步管理仓库进销存（订单发货自动扣减库存）;

- 支持设置安全库存（库存预警值）;

- 支持打印货品条码;

- 支持货架位/包材管理;

- 支持仓库盘点/调拨/退货管理;

- 支持4种不同采购模式;

- 支持1688/拼多多/淘供销一键下单;

- 支持按公式自动生成采购建议，避免漏采/多采;

- 支持同步查看采购单物流信息;

- 支持采购单标记付款，管理收支信息;

- 支持按单采购，采购到货对应订单直接打包发货。

### Ozon数据财务

- 支持统计店铺业绩;

- 支持统计产品销量;

- 支持统计客户下单分布国家;

- 支持统计单位时间内发布新产品数量;

- 支持统计仓库商品出入情况;

- 支持统计仓库商品利润情况;

- 支持统计采购员采购情况;

- 支持统计各供货商供货情况;

- 支持统计店铺利润情况;

- 支持添加财务账号，管理收支明细。

## Ozon店铺授权操作教程

- 需要开通VIP才能授权Ozon店铺（本土店铺不支持授权）。

- 授权后，仅支持通过小秘处理订单，不支持发布产品。

### 授权流程

登录Ozon后台，按下图路径获取授权信息。

![](../../images/318447a1a3dc4b44.png)
