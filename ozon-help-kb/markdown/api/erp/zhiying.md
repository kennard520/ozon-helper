## ERP介绍

杭州智赢科技有限公司成立于2015年,是一家专注于革新传统跨境电商模式服务平台。其产品智赢ERP是覆盖跨境电商多平台运营卖家提供高效的店铺管理工具。并且智赢通过ERP工具打造了完善的跨境电商入门服务、跨境电商供应链生态服务、以及跨境电商周边服务为一体的综合性孵化服务平台。

## 支持功能汇总

### 产品管理

- 支持Ozon单个多个sku产品刊登和批量上传；

- 产品批量编辑；

- 批量更新产品库存、价格、图片、描述信息；

- 类目查找、属性中文翻译；

- 图片在线编辑功能：图片文字翻译、多语言翻译俄文，产品图片位置调整，图片一键白底、首图调整；

- Ozon定价计算器，Ozon物流渠道运费计算器；

- 富文本编辑上传。

### 订单管理

- 订单管理、自动提醒买家提供护照信息、发货面单打印；

- 订单成本利润统计核算；

- 订单产品货源查询；

- 系统转运仓代贴面单送仓服务。

### 客服消息

客服消息接收，中文一键翻译回复。

### 选品数据支持

- 产品销量查询；

- 产品库存数量；

- 产品售价币种换算；

- 销量趋势查询。

## 授权流程

打开 ozon 后台，点击右上角“个人”，跳转设置后台，左侧选择 API 密钥，复制客户 ID，
 及生成密钥（密钥只显示一次）。

![](../../images/7325bb9037c51c58.png)
生成密钥。

![](../../images/fc04ba193d7ebaa7.png)
打开 erp，选择 ozon 选项，左侧点击账户授权，左下角点击添加 Ozon 授权 将后台复制的 ID 及访问密钥粘贴复制，然后点击验证
 Token。

![](../../images/af0d2fe89f80a229.png)
显示更新 Token 即可，开户人及公司名称填写作为备注，建议填写店铺执照法人及公司名称，ozon 的币种一般根据后台结算币种进行填写，这里后台是以美元结算，选择美元即可；
 填写完毕点击确认保存，提示操作成功确定即可。

![](../../images/ff31cbe96a09cd72.png)
