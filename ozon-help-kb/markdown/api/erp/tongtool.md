## Ozon店铺授权操作教程

- 购买Ozon平台

[https://market.tongtool.com/application/market/index.html](https://market.tongtool.com/application/market/index.htm)
。

位置：服务——应用市场——销售渠道——Ozon，购买即可使用（1000元购买后永久免费使用）。

![](../../images/cdcf4912fc2855a3.webp)

- 用户客户ID、API密钥信息获取：

位置：店铺后台—设置—API 密钥—复制客户
 ID—选择管理员—自定义名称—点击创建密钥—复制生成的密钥信息。

![](../../images/318447a1a3dc4b44.png)

- 授权Ozon店铺：

- 启用Ozon平台
 位置：基础设置——渠道管理——启用Ozon。
授权Ozon店铺
 位置：基础设置——账户管理——渠道选择“Ozon”——点击“添加”。

![](../../images/bee989005f1ea490.png)
在下图界面设置订单前缀、账户名称、交易费比例，客户ID、API密钥（店铺后台获取，如上），如需授权子账号，相应勾选即可，设置完成后点击“添加“。
授权成功后，在系统基础设置——通用账户管理处，“Ozon状态”为“有效”，账户授权成功。在“数据同步”处，需鼠标左键点击，开启抓取Ozon订单、同步发货状态功能。

![](../../images/780cf4945b969109.png)
