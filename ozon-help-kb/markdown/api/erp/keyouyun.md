## ERP介绍

客优云隶属于湖南智六网络科技有限公司，2018年开始深耕跨境电商和企业服务领域，是最早一批提供跨境SaaS服务的企业。公司聚焦于跨境ERP系统以及软件工具的研发，致力于为企业和用户提供最优质的跨境服务。

截止2023年6月，客优云累积注册用户超30万，日可处理订单量超5000万，合作优质物流商50多家。是Ozon、Shopee、TikTok
 Shop、Lazada等多家平台的官方认证及最佳ERP合作伙伴，提供采集、刊登、定价、订单、仓储、采购、物流、代打包、财务等一站式跨境服务。

## 支持功能汇总

### Ozon产品采集刊登发布

- 采集产品并发布至Ozon；

- 快速映射采集源产品与Ozon产品规格信息；

- 图片翻译、图片美化、水印设置、首图设置；

- Ozon定价模板；

- 发布产品
(定时发布、自动翻译产品信息、防重复发布、标题去重)；

- 币种设置；

- 常用模板管理；

- 在线产品管理；

- 添加富文本描述信息；

- 支持上传产品封面视频、产品描述视频。

### Ozon订单处理

- 支持授权/管理Ozon物流；

- 实时同步Ozon订单；

- 支持打印拣货单、打印面单、打印配货单
(批量和单个操作)；

- 支持预报发货操作；

- 支持多维度查询订单；

- 支持拆分包裹；

- 支持审核订单；

- 支持设置黑名单；

- 支持处理流程自定义
(设置适合自己的订单处理流程)。

### Ozon库存管理

- 支持添加多个自营仓库；

- 支持授权第三方海外仓，同步库存；

- 支持添加单个/组合/多属性/加工商品；

- 支持从其他ERP导入商品；

- 支持同步管理仓库进销存
(订单发货自动扣减库存)；

- 支持设置安全库存
(库存预警值)；

- 支持打印货品条码；

- 支持货架位/包材管理；

- 支持仓库盘点/调拨/退货管理；

- 支持1688/拼多多/淘供销一键下单；

- 支持按公式自动生成采购建议，避免漏采/多采；

- 支持同步查看采购单物流信息。

### 报表统计

- 产品销售金额/销量统计；

- 订单利润统计；

- 店铺营收统计。

### 子账号权限管理

根据跨境电商业务和平台设置不同子账号及对应账号权限。
