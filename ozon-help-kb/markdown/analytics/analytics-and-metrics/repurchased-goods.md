在
[分析 → 购买的商品](https://seller.ozon.ru/app/analytics/redemptions)
部分您可以查看：

- 商品认购水平：您将看到销售水平是否因取消和退货而产生下降；

- 取消和退货的常见原因：您将了解应首先对哪方面进行优化，比如配送速度或包装质量；

- 每件商品的指标动态以及取消和退货原因。

## 指标计算

我们为每件商品最近50个订单的认购百分比进行计算。如果订单量低于50，那么我们将把所有订单纳入计算。比如，如果商品被订购了10次，那么在计算指标时我们会把10个订单纳入计算。

商品认购水平根据以下公式进行计算：

**(订单数量−退货数量−取消数量)÷订单数量**

比如，如果商品被订购了50次，取消了3次并退货了2次，那么它的认购水平将为(50–3–2)÷50=90%。

我们将所得出的认购水平与类目和价格区段平均指标进行比较。因此认购水平可以分为低水平、中等水平和高水平。对于不同类目和价格区段，同一认购百分比可能为不同的水平。

比如，对于价格高于1000卢布的“服装”类目商品而言，90%为高水平；而对于价格低于1000卢布的“宠物用品”类目商品而言，该百分比则为中等水平。您可以在
[表格](#每件商品的分析)
中查看您商品的具体阈值。

## 每件商品的分析

在
[分析 → 购买的商品](https://seller.ozon.ru/app/analytics/redemptions)
部分下半部分的表格中您可以：

- 查看您的商品列表、其总统计数据以及每件商品的统计数据；
查看特定类目的认购水平；
下载商品认购信息报告。
商品在表格中是根据认购水平排列的——认购水平最低的商品位于表格的上方。在默认情况下将显示所有商品的统计数据。

商品行中包含该商品最近50个订单的认购百分比：红色为低认购水平，黄色为中等认购水平，绿色为高认购水平。如要在列表中找到商品，请使用货号或筛选器进行搜索。

商品行中包含以下水平的阈值——每个类目和价格区段的阈值都不同。比如如果商品的认购水平为中等水平且指标为60%，而右侧显示的阈值为90%，则说明对于该商品，90%以上的认购水平将被认为高水平。

![](../../images/3fc77860cdbb3780.png)

如要查看商品最近28天的详细分析，请点击商品行。图表上显示的是该时期内每天的数据：

商品订单总数，

- 认购份额，

- 取消和退货份额。

图表下方为最近28天内的一般度量：

- 已订购；

- 已取消；

- 已退货；

- 已认购；

- 周转损失：如果买家认购了取消和退货的订单，它们将为您带来多少收入；

- 最近50个订单的常见取消原因。

[有关取消和退货常见原因的更多信息](#取消和退货的可能原因)

如要根据类目查看数据，请开启
**根据类目**
筛选器——这样您将可以在您销售的每个类目中评估您商品的认购水平。

## 取消和退货的可能原因

在
**50个订单的取消和退货原因**
选项卡中包含每个商品的取消和退货原因。以下为其中一些的说明：

| 原因 | 说明 |
| --- | --- |
| 您违反了平台规定 | 可能我们发现了您有违禁商品的卡片或其他违反规定的行为，因此不得不取消了订单。
[商品封锁原因](/launch/quality-assurance/ban/#商品屏蔽原因) |
| 无法配送订单
 无法处理订单 | 可能商品包装不当。请按规定包装货件，使包装结实且能够保证商品安全运送。
[订单包装要求](/fulfillment/rfbs/logistic-settings/order-packaging-requirements/) |
| 销售限制 | 俄罗斯联邦法律已规定您类目中的商品
[销售限制](/products/requirements/special-categories/)
。 |
| 配送服务无法取走订单
无法在配送服务中注册货件 | 可能配送服务在接收和配送订单时遇到了问题：比如商品上的标签不可读。请保证您已遵守配送服务的所有规定并留下了可以与您联系的正确的电话号码。
[订单包装要求](/fulfillment/rfbs/logistic-settings/order-packaging-requirements/) |
| 无法根据追踪号码追踪订单 | 如果买家无法在配送服务的网站上追踪订单，那么他们可能会取消订单。 |
| 买家未指出原因 | 商品没有问题，但买家不想买了。 |
