### 你能从分析中学到什么？

> > 拥有
> [Premium Plus](/promotion/subscriptions/premium-plus)
> 和
> [Premium Pro](/promotion/subscriptions/premium-pro-global)
> 订阅可查看完整分析。拥有
> [Premium](/promotion/subscriptions/premium)
> 和
> [Premium Lite](/promotion/subscriptions/premium-lite-global)
> 订阅以及没有订阅时，可以查看部分指标。
>

借助该工具，您可以查看有多少买家在搜索中查找并看到您的商品，其中有多少人进入商品卡片并下单。我们会针对每件商品显示与竞争对手对比的分析。
[如何将自己商品的指标与竞争对手进行对比](/analytics/analytics-and-metrics/products-in-search-results/visibility-of-your-products-in-the-search#как-сравнивать-показатели-своего-товара-с-конкурентами)

我们会在分析中显示：

- 买家在Ozon搜索结果中看到或订购的您的商品；

- 买家看到或购买您商品时使用的搜索查询；

- 每件商品与竞争对手商品对比的指标。

数据的计算有1-2天的延迟。如果您添加了新商品，我们会在出现浏览量或销售后立即显示分析。您可以在
[“索引错误”报告](/analytics/fulfillment-reports/indexing-errors)
中检查商品是否存在问题以及是否对买家可见。

### 如何检查商品的可见性

- 请打开
**[“分析” → “搜索可见性”](https://seller.ozon.ru/app/analytics-search/search-results/apz)**
部分，并切换到
**“我的商品”**
选项卡。将显示您的所有商品——排在最前面的是在搜索中被看到次数较多的商品。
[显示哪些指标](/analytics/analytics-and-metrics/products-in-search-results/visibility-of-your-products-in-the-search#какие-показатели-можно-узнать-в-аналитике)

- 请使用筛选器：

- 类目——各个类目中的商品。

- 商品特征——仅在Select平台销售的商品，或同时在Select和Ozon平台销售的商品。

- 平台——所选平台的指标：Select或Ozon。例如，如果选择“Select”，我们将在表格中只显示该平台的数据，不计入Ozon的数据。

- 请点击
**“查看所有搜索查询”**
——我们将显示您的商品最常被浏览或订购时使用的搜索查询，以及相关统计数据。

拥有
[Premium](/promotion/subscriptions/premium)
、
[Premium Lite](/promotion/subscriptions/premium-lite-global)
、
[Premium Plus](/promotion/subscriptions/premium-plus)
或
[Premium Pro](/promotion/subscriptions/premium-pro-global)
订阅，可以下载包含商品全部搜索查询和指标的XLS文件。为此，请选择所需商品并点击
**“下载XLS”**
。

## 如何将自己商品的指标与竞争对手进行对比

请打开
**[“分析” → “搜索可见性”](https://seller.ozon.ru/app/analytics-search/search-results/apz)**
部分，并在所需商品所在的行中点击
**“前往商品分析”。**

- 请选择期间以及您想要对比指标的竞争对手商品。

- 我们会在页面上显示：

- 在
**“指标”**
模块中——您的数据与竞争对手商品的对比。

- 在
**“动态”**
模块中——各项指标按天或按周的变化图表。

- 在
**“商品查询”**
模块中——所选商品全部搜索查询的搜索统计数据。请选择
**“竞争对手商品”**
或
**“对比”**
选项卡，查看竞争对手商品在相同搜索查询下的指标。

### 分析中可以了解哪些指标

> > 部分指标仅在拥有
> [Premium](/promotion/subscriptions/premium)
> 、
> [Premium Lite](/promotion/subscriptions/premium-lite-global)
> 、
> [Premium Plus](/promotion/subscriptions/premium-plus)
> 或
> [Premium Pro](/promotion/subscriptions/premium-pro-global)
> 订阅时可用。
>

| **指标** | **含义** |
| --- | --- |
| 有多少买家搜索过 | 有多少独立用户使用过该搜索查询——无论他们是否看到了商品。 |
| 有多少买家看到过 | 有多少独立用户通过该搜索查询看到了商品。 |
| 在搜索中的位置 | 在该搜索查询下，不考虑筛选器和排序时，商品在Ozon搜索结果中平均显示在第几位。计算方式：将所有位置数值相加，再除以搜索查询的数量。 |
| 从搜索到商品卡片的转化率 | 在该搜索查询下，商品卡片访问次数与搜索中展示次数的比值。 |
| 从搜索到订单的转化率 | 在该搜索查询下，订单数量与搜索中展示次数的比值。 |
| 根据该搜索查询订购的商品数量 | 按搜索查询统计的订购商品件数，包括取消和退货。 |
| 根据该搜索查询已订购金额 | 通过搜索查询订购的商品总价格。我们会计入所有订单，包括取消和退货。 |

##
为什么分析中的数据不完整

| 新商品没有分析 | 如果您添加了新商品，我们会在出现浏览量或销售后立即显示分析。您可以在
[“索引错误”报告](/analytics/fulfillment-reports/indexing-errors?region=CHN)
中检查商品是否存在问题以及是否对买家可见。 |
| --- | --- |
| 并非所有能找到商品的搜索查询都会显示 | 只有买家在其搜索结果中看到或购买了商品的搜索查询才会进入分析。
如果某个搜索查询没有出现在分析中，说明还没有买家在搜索结果中翻到您的商品。 |
| 显示了商品的购买，但没有浏览量 | 买家可能先将商品加入购物车，几天后才下单，而不是立即下单。 |
