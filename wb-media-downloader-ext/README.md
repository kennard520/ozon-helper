# WB 图片视频下载器

## 安装

1. 在本目录运行 `npm install`（仅用于本地测试；插件运行不需要 Node.js）。
2. 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `wb-media-downloader-ext`。

## 使用

打开 `https://www.wildberries.ru/catalog/<商品ID>/detail.aspx`，确认页面能正常显示商品信息后，点击右下角“下载全部变体素材”。

插件会读取当前商品卡，发现同一商品下当前可解析的变体，并按变体下载轮播图、详情图和商品视频。任务完成后，如果存在失败项，可点击“重试失败项”继续补下载。

## 保存位置

下载文件会保存到浏览器默认下载目录下的分层路径：

`下载/WB下载/<商品标题>_imt-<商品组ID>/<时间批次>/<变体>/轮播图|详情图|视频/`

每个变体会单独建目录；轮播图按 WB 商品图顺序保存，`rich_v1.json` 中的内容图片只保存到“详情图”，视频保存到“视频”。

## 权限

- `downloads`：创建、监控和取消用户主动发起的媒体下载，并在需要时打开下载目录。
- `storage`：临时保存当前下载任务进度，便于面板刷新后恢复任务状态。
- WB 域名权限：读取 Wildberries 商品卡、卖家详情图、商品图片和商品视频；插件不会抓取评论区图片，也不会访问非 WB 媒体域名。

## 故障排查

- “card.json 不可用”：刷新商品页后重试，并确认 WB 页面本身能正常显示商品；若商品已下架或 WB CDN 暂时不可用，需要等待 WB 恢复。
- 个别变体失败：任务完成后点击“重试失败项”；仍失败的项目会保留在下载结果中，方便确认具体 URL。
- 没有视频：该变体未声明商品视频，不属于下载失败；不同变体的视频不会互相复制替代。
- 找不到文件：在任务结果中点击“打开下载目录”，浏览器会定位到本次批次中已下载的文件。
